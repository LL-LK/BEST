# F 通道可用：不稳只集中在**键有争议**的两格（2026-10-11）

> **结论**：F 通道（取数调用与参数）在 B3 × 3 轮下 **6/8 格三轮完全一致**；
> 仅有的 2 格不稳（`C02`、`D11`）**成因都是题面/键的争议**，不是模型随机。
> ⇒ **F 通道可以作为主指标**，前提是**题面把每个参数都钉住**。
> —— 这与路由通道（判定不可用）形成鲜明对照。

---

## 一、F 通道的稳定性：6/8 完全一致

各轮都发调用的格（F 通道可比）共 **8/24**：

| 题 | 三轮一致性 |
|----|-----------|
| `D01` | ✓ 完全一致（5 字段） |
| `D02` | ✓ 完全一致（7 字段） |
| `D06` | ✓ 完全一致（6 字段） |
| `D09` | ✓ 完全一致（4 字段） |
| `D10` | ✓ 完全一致（6 字段） |
| `D12` | ✓ 完全一致（5 字段） |
| **`C02`** | ✗ 调用**个数与内容**都变 |
| **`D11`** | ✗ 仅 `max_rows` 变（3 / 未给 / 未给） |

**6/8 = 75%**，且**这 75% 是被 2 格拖下来的**；余下 6 格是**逐字段完全一致**。
（对比：路由通道逐题一致率只有 83–96%，且**摇摆散布在多题上**。）

## 二、两格不稳的成因都是**争议**，不是随机

### `C02` —— 键与代理对"星表算不算缺"读法相反

| | 内容 |
|---|---|
| 问句 | 「查找 RA=120.3°、Dec=−20.4°、半径 5″ 内的**标准星**。」 |
| **冻结键** | `route: clarify`，`expect_tools: []` |
| 三轮实测 | ① `list_catalogs()`；② `list_catalogs()` + `cone_search(catalog="standard_stars")`；③ 直接 `cone_search(catalog="standard_stars")` |

代理的读法：**「标准星」已经点明了星表类别**，所以星表不算缺 → `answer`；
键的读法：**没给星表 id** → 缺参数 → `clarify`。

**两种读法都站得住**，而三轮各发各的调用正是这个歧义的表现。

### `D11` —— 题面**没有钉住** `max_rows`

| | 内容 |
|---|---|
| 问句 | 「…给我 ps1 **三个源**的 r 与 g 波段星等及误差。」 |
| **冻结键** | `expect_tools: [{... "max_rows": 1000, "optional": false}]` |
| 三轮实测 | ① `max_rows=3`；② 未给；③ 未给 |

题面说"**三个源**" ⇒ 一代理取 `max_rows=3`（**字面正确**）；键说 1000。

**题面本身没有钉住这个参数**，所以它必然摇。

## 三、可修，且修法明确

| 格 | 修法 |
|----|------|
| `C02` | 二选一：① 题面**不要**点明星表类别（改说"帮我找标准星，星表你定"）→ 键的 `clarify` 成立；② 或把键改成 `answer`，并在题面给出星表 id。**现状两边都不满足，故必摇** |
| `D11` | 键改为**不要求** `max_rows`（因为题面只说了"三个源"，没给行预算）；或题面显式给出行预算 |

**共同根因**：**题面没有把每个参数钉死** ⇒ 代理的合理补全与键的期望不一致 ⇒ 抖动。
这与之前 `R03`/`R05`/`R09`/`R26`/`R31` 五次要事故**同源** —— 都是"题面留了自由度"。

## 四、这对实验设计的意义

| 通道 | 稳定性 | 可用性 |
|------|--------|--------|
| **路由** | 逐题 0.833–0.958，摇摆散在多题 | ✗ **不可用作主指标** |
| **F 通道** | **逐字段完全一致 6/8**，不稳集中在 2 格**争议题** | ✓ **可用**，前提是钉死参数 |

⇒ **下一步应把主指标从"逐题 route"改为"F 通道的逐字段一致率"**，
并**先把 `C02`/`D11` 这类参数未钉死的题改掉**（改题面或改键，二选一，不能两边都不动）。

**注意样本量**：F 通道可比格只有 **8/24** —— 因为 `clarify`/`reject` 是零调用。
要放大 F 通道的样本，需**增加"有明确取数参数"的题**，而不是增加轮次。

## 五、当前不能声称的

* 不能声称 F 通道的噪声底已确定 —— **n=8 太小**，6/8 的 95% 置信区间很宽；
* 不能声称 `C02`/`D11` 的键"错了" —— 只说**题面与键没有对齐**，两种对齐方式都可行；
* 不能据此声称任何组件效应 —— 本轮只做**通道可用性**判断，未做任何装配比较。

## 六、修完之后的验证：F 通道 **7/7 = 1.000**

两处修法落地后重跑 3 轮（`b3_v2/v3/v4`）：

| 修法 | 内容 |
|------|------|
| **D-19（新缺陷）** | 数据面摘要原来**只提了 `ps1`**，12 个星表 id 一个没给 ⇒ 代理只能猜。补上完整清单 |
| **D11 键** | 去掉 `max_rows`（题面只说了"三个源"，未给行预算，键不该钉它） |

### 6.1 `C02` 的根因是**我的规格缺口**，不是代理乱猜

| | 三轮实测的 `catalog` |
|---|---|
| **修前** | `None` / `standard_stars` / `standard_stars` —— **2 次是枚举外的 id** |
| **修后** | **`landolt` × 3** —— 全部在枚举内 |

真实枚举里有 `landolt`（Landolt 标准星）而**没有** `standard_stars`。
代理"发明"这个 id，是因为**我根本没把清单给它**。补上清单后它立刻选对了，且**完全稳定**。

⇒ 这是本项目第 **七** 次由"提示词缺一个事实"引起的缺陷（前六次：D-13/14、R03/R05/R09/R26/R31）。

### 6.2 正确的 F 通道指标：**只比键钉住的字段**

`D11` 的 `max_rows` 在修后仍轮间变化（`None`/`3`/`3`）—— 但**键已声明不要求它**。
若仍把它计入不一致，就是"修了键也白修"。故指标应为：

> **只比较该题键里 `expect_tools[].args` 出现过的字段。**

| 条件 | F 通道一致率（只比键钉住的字段） |
|------|------------------------------|
| 修前 | 7/8 = 0.875（`C02` 挂） |
| **修后** | **7/7 = 1.000** |

**⇒ F 通道修后逐格完全稳定。**

### 6.3 这条口径与"键只钉题面能决定的参数"自洽

评价口径必须与制键原则一致：
* 键**钉了**某字段 ⇒ 该字段轮间变化 = **不一致**（记偏离）；
* 键**没钉**某字段 ⇒ 该字段轮间变化 = **不记**（题面本来就没决定它）。

否则会出现"键放松了要求、指标却仍按老要求扣分"的自相矛盾。

## 七、结论更新

| 通道 | 修前 | 修后 | 可用性 |
|------|------|------|--------|
| 路由 | 0.875–0.917 | 0.833–0.889 | ✗ 仍不可用作主指标 |
| **F 通道（键钉住字段）** | 0.875 | **1.000** | ✓ **可用，作为主指标** |

**可声称**：在"题面钉死参数 + 键只钉题面能决定的参数"两条都满足时，
**F 通道逐格可复现**（3 轮 7/7）。

**仍不可声称**：任何组件效应 —— 本轮只做通道验证。且 **n=7** 太小，
只能说"未观测到不稳"，不能说"噪声为零"。
