# docs/archive/temp-artifacts-2026-10-07.zip — temp/ 结论性产物归档

## 这份包是什么

`temp/` 是本仓的临时区（铁律 3，gitignored）。2026-10-07 回放层退役时，
把其中**结论与证据**打包留档到远程：审计报告、分片结论、施工坑单页、
判据级红测试的探针脚本。

## 为什么不是 temp/ 全量

实测 `temp/` = **5178 MB / 121303 文件**。其中约 **2741 MB** 是变异实验临时克隆的
**仓库副本**（`*_clone` / `k1` / `j7` / `A6-mutant` 等）——它们是别人仓的拷贝，
证据价值近零而体积过半。其余里还有大量逐字节重复的实验产物（实测去重省下
**275 MB**）。

所以本包收的是 `.md` / `.txt` / `.py` / `.ps1`：**6334 个文件 / 20.42 MB**。
刻意不收 `.json` / `.yaml` / `.csv` —— 那三类合计约 700 MB，内容是逐 run 的产物
矩阵（同一道题 × 多个 attempt × 多个系统），对回查结论没有增量价值；而且题集与
清单类的结构化元数据本来就随仓入库，不必在这里再存一份。

## 隐私处理

打包时**抹平本机绝对路径**（`<LOCAL_PATH><用户名>\...` → `***`）：实测记录里夹着
本机路径与 Windows 用户名，推上远程等于公开本机账号名。**只抹路径，不改任何
结论数字**；指纹按脱敏后内容计算，所以收信人核对指纹时对得上包内字节。

其余三类扫描命中**均已逐个核实为误报**，如实登记以便复核：

| 类别 | 判定 |
|---|---|
| 口令赋值 | 全是**环境变量名**（`ENV_CLIENT_SECRET = "NADC_OAUTH_CLIENT_SECRET"`）或**单测夹具**（`ASTRO_BEST_PASSWORD='secret123'` 是 dotenv 单测的假口令） |
| PEM 私钥 | 唯一一处是 `priv1_zip_scan.py` 里的**探针自造假私钥** —— 那脚本的任务就是扫包里的私钥，自己得先有一把假的 |
| 邮箱 | 全是测试用假域名（`pw@evil.example` / `git@github.com` / `p@x.org`） |

**结论：包内无任何真实凭据、密钥或个人信息。**

## 怎么用

包内 `MANIFEST.txt` 是权威清单：

1. 逐文件 sha256（脱敏后）+ 相对 `temp/` 的路径 + 隐私命中标注；
2. 收集口径与排除理由；
3. 隐私扫描的逐类人工裁定。

按条目编号回查时的纪律（同 `docs/REPLAY-RETIREMENT-CRITERIA.md` §3）：
**行号会漂移**，任何路径与行号先实跑或 `git show` 复核再引用。
