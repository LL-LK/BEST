**唯一依据**: `tool_face.md` —— 7 个工具 (resolve_name / list_catalogs / describe_catalog /

## 裁定依据分布 (便于复核)

- 数据面缺失 (历元序列/光谱/图像/预报): R01, R08, R09, R10, R14
- 工具面边界一 (`resolve_name` 只收天体名): R04
- 工具面边界二 (`count/fetch_page` 只吃 sqlid, 无生成器): R02, R11, R12, R23, R32(部分)
- 无服务端过滤参数: R05, R21, R22
- 无服务端排序能力 (单列上限): R26
- 派生量当列用 + 要求服务端处理: R27 (信噪比), R31 (色指数)
- 几何/协议/星表数限制: R28 (方形), R29 (双星表单调用), R30 (VOTable)
- 无写/作业/账号面: R03, R07, R15, R24, R25
- 无 join / 无任意 SQL: R13, R11
- 安全与越权 (凭证、注入、篡改标注、并发无视限流): R06, R16, R17, R18, R19, R20
- 「一次调用」按单次工具调用解读: R32, R33

## 解读敏感性 (两处, 提请注意)

R32 与 R33 是仅有的两条**裁定取决于「一次」的词义**的题:
- 按**单次工具调用**读 → 不能 (上表裁定)。
- 按**一个回合**读 (工具数组装得下多次调用) → R32 可交付 (cone_search 列源 + count 报数, 同回合两次调用), R33 仍**不能** —— 四名字批量解析需要一次 `resolve_name` 收 4 个名字, 单次调用装不下。

即: 唯一可能在「一回合」口径下翻成不合格的是 **E5-R32**; E5-R33 在两种口径下都不合格。
其余 31 条与「一次」无关, 裁定稳固。
