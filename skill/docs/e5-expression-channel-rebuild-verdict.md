# E5 表述通道重建结论: 独立重采**不能**修复该通道 (2026-10-10)

> 一句话结论: 用 90 个互不可见的独立会话、并把**完整真实信封**交给作答者之后,
> 表述通道的通过率不是回升, 而是**塌缩到 3.4%**, 且三轮零方差 —— 这是**分辨力丧失**,
> 不是稳定。故**表述通道无法通过重采变成有效证据**; 它是"模板复述符合度", 不是可测的科学量。

## 三、为什么"p=1.0"不等于"可交换"

E 通道三轮都是 0.034、极差 0 —— 若只看 p 值, 会得到"实测极差在零假设下毫不极端 → 可交换"的绿。
但这是**假绿**: 每轮期望成功数只有 `29 × 0.034 ≈ 1`, 极差统计**根本没有分辨力**。
一个 96.6% 都不过的通道, 三轮全等是必然的, 与"稳不稳"无关。

这正是本次事故前我在别处批评过的同一类错误 (拿退化输入报绿), 只不过这次出在我自己的判据里。

## 四、本轮修掉的两个判据缺陷 (都属 fail-open)

1. **退化判定写在 `elif` 里** —— `pooled` 落在开区间 `(0,1)` 时永远走不到退化分支,
   而"期望成功数仅 1"的通道恰恰落在那里。已改为**独立于 p 值分支**判定。
2. **`pass` 不看 `degenerate`** —— 只要 `p >= 0.05` 就记"可用", 于是塌缩通道拿到绿。
   已改为 `pass = (p_value >= 0.05) and (not degenerate)`。

判据: **期望成功数或期望失败数 < 2 即记分辨力不足** (n·pooled < 2 或 n·(1−pooled) < 2)。
回归: `evals/ablation/tests` 70 passed 未破。

## 五、真正的结论 (对 E5 方案的影响)

表述通道的 `critical` 断言是照着 **ScriptedLLM 渲染器的输出**写的 (逐字短语), 它测的是
"有没有逐字复述模板", 而不是"事实说对了没有"。证据链:

* 重采前 (旧采集表): 三轮 0.533 / 0.233 / 0.233 —— 有梯度, 是**采集侧轮次污染**;
* 重采后 (本批独立会话): 三轮 0.034 —— 梯度消失但**通过率塌缩**;
* 两批的公共点: 自由行文的作答者**几乎不可能**同时命中一条题的 4–5 个逐字短语。

因此 §15.5 把"重采独立 attempt"当作表述通道的转正路径是**不成立的**。
可行的替代只有一条: **把 E 断言从"字面短语"改成"可机检的事实"** ——
即从观测结果里导出应有事实 (行数/三元组/来源标识/关键列值), 再**语义比对**答案是否陈述了它们,
而不是要求出现固定字符串。这一步属**判据重写**, 不是采集问题。
