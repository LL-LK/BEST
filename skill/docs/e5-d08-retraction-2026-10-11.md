# 撤回：D08 的差异**不是** `param_validation` 的组件效应（2026-10-11 更正）

> **本文件撤回 `docs/e5-first-attributable-ablation-d08-2026-10-11.md` 的核心断言。**
> 该断言基于 **3 个装配**；扩到 **12 个装配**后**不成立**。
> 撤回理由与替代结论如下。

---

## 一、原断言

> 「A1 = `answer`，A3 = `clarify`，B3 = `clarify`；A1 = B3 减去 `param_validation`，
> A3 = B3 减去 `refusal_rules`，且 A3 ≡ B3 ⇒ 差异**恰好由 `param_validation` 造成**。」

## 二、用 12 个装配复核 ⇒ **不成立**

| 装配 | `param_validation` | D08 route |
|------|-------------------|-----------|
| A1 | ✗ | `answer` |
| **A2** | **✓** | **`answer`** |
| A3 | ✓ | `clarify` |
| A4 | ✓ | `clarify` |
| A5 | ✓ | `clarify` |
| **A6** | **✓** | **`answer`** |
| B0 | ✗ | `reject` |
| B1 | ✗ | `reject` |
| B2a | ✗ | `clarify` |
| B2b | ✗ | `clarify` |
| B3 | ✓ | `clarify` |
| sham | ✓ | `clarify` |

| 分组 | D08 route 分布 |
|------|---------------|
| **有** `param_validation`（n=7） | `answer` ×2 · `clarify` ×5 → **混合** |
| **无** `param_validation`（n=5） | `answer` ×1 · `clarify` ×2 · `reject` ×2 → **混合** |

⇒ **同样带该组件的臂给出不同 route** ⇒ 该组件**不决定** D08 的行为。
原断言是从噪声分布里抽到的一对样本。

## 三、替代结论：这是**运行间方差**，不是组件效应

D08（`radius_arcsec=0`）在 12 个装配上产出 **3 种 route**，而其中 7 个装配
**共享同一 `param_validation` 取值**。⇒ 该题的判定在**同一条件内**就不稳定。

**这是一个关于方法学的、比原断言更重要的结果**：

> **单次采样的装配差异不可归因。**
> 3 臂时看到的「A1 vs B3」差异，扩到 12 臂后淹没在同类臂的散布里。

它同时**验证了方案里"每格 ≥3 轮次"那条修订的必要性** ——
没有轮内重复，就无法把「组件效应」与「同条件散布」分开。
（本轮数据仍是**每格 1 轮**，故**连这个替代结论本身也还是初步的**：
它说明了"必须做重复"，但**尚未**给出重复后的方差估计。）

## 四、对全量采集的直接影响

| 项 | 修正后的做法 |
|----|-------------|
| **归因门槛** | 单臂单轮**不得**用于归因；至少需同条件多轮，看**类内一致 / 类间分离** |
| **本轮数据用途** | 只用于**筛选有方差的题**（16/24 有路由方差），**不用于**下效应结论 |
| **D08 的地位** | 从"第一个可归因差异"降为"**方差最大的题之一**"——它证明的是噪声有多大 |
| **判据文档** | `docs/e5-criterion-precheck-vs-toollayer-2026-10-11.md` 的口径仍然有效（它定的是**怎么记**，不是断言效应存在） |

## 五、这次撤回本身的价值

本项目已反复栽在「把噪声当效应」上（R 类 6→20 题时的 `ΔRejectAcc` 分子恒为 1 题、
R04 的单点分歧、现在的 D08）。**区别在于这次是判据自己抓到的**：
全量网格一铺开，原断言就站不住了。

⇒ **结论**：**多做臂、多轮重复，比多推一层解释更值钱。**
下次再看到"恰好由某组件造成"的说法，先问一句：**同类条件里有几个样本？**
