# E3 — 科学语义区分与幻觉抑制评测方案

> **编号说明（2026-09-28 已按 E6 附录 B 终版裁决回改）**：本文档的 E3 指「科学语义与幻觉」评测。
> 终版编号台账：E1 工具调用 / E2 金标准 / E3 语义（本文）/ E4 鲁棒性与安全失败 /
> E5 基线与消融 / E6 可复现性·效率·可用性 / **E7 在线漂移检测** / **E8 TAP 面一致性（或并入 E2 D 面）**。

> §1.2/§2 的旧预留表述同样以本台账为准。
> （另：本仓 `docs/architecture/` 里的 E1/E2 是治理债务条目，与本实验序列无关，勿混淆。）

> **定位**：E3 评的是**"拿到数据之后怎么说"**——能不能分清静态测光与时序、
> 合成星等与单次曝光、星等与流量、哨兵与真值、Gaia 身份与 BEST 测量、
> "库里没有"与"天体不存在"、"没标变星"与"确定不是变星"。
> 与既有实验的关系：
> - E1 评**决策**（听到人话后该调哪个工具、传什么参数、该不该拒）；
> - E2 评**取数**（冻结快照上，交出来的行和数与人工金标准是否逐格一致）；
> - **E3 评解释**（在 E1/E2 都做对的前提下，说出来的话有没有科学错误、有没有编数）。
> 三者正交：E2 全绿而 E3 红，等于"取数全对但讲错了"——这正是天文 skill 与普通 API
> 包装器最该拉开差距的地方，也是 E3 存在的唯一理由。

## 0. 术语对照（给非算法背景读者）

| 说法 | 大白话 |
|------|--------|
| 语义轴 | 一组"容易讲错"的科学区分点，本方案共 7 组（见 §4） |
| fixture（夹具） | 题面里直接给的一段"你刚从 BEST 查到的数据"，**离线、固定、可反复重跑** |
| 构造样本 | fixture 里的数是**编的**（为测语义而造），不是真实天体测量值；但列名、单位、哨兵规则是真的 |
| 哨兵值 | 拿一个不可能出现的数表示"这里没数据"，常见的是 `-999`（测光缺失）、`-1000`（名称解析失败），但**远不止这两个**：实测还有 ≈-1000 的**带**（`-1004.07`/`-1004.08`…，浮点精确相等一个都命中不了）、`uss_dr1` 的定点 `-32768`、字面 `nan`、空串 `""`。判定"缺失"的规则是**值 ≤ 阈值**而不是"等于某个值"；逐表形态以 `evals/_data/null_sentinel.yaml` 为准 |
| 无来源数值 | 回答里出现、但在给定数据里找不到出处、也没写清怎么算出来的数 |
| 限定语 | 说一个数时必须附带的条件：哪张表哪一列、误差多少、什么测光系统 |
| ~~盲评 / Cohen's κ（卡帕）/ Krippendorff's α / Gwet's AC1 / ICC~~ | **已取消（2026-10-03 起，LLM-only）**。这五个都是"两个人打同一批题"才成立的统计量，κ 尤其只能由**两个真正独立的人**算出。本方案不设评阅人，故一律**不计算、不报告**；取消理由见 §8.1，已取消清单见 §10 |
| McNemar 检验 | 两个系统在同一批题上"谁对谁错"的配对比较，专治"总体差不多但逐题不一样" |
| 反证夹具 | 故意掺进来的"已知坏回答"；**判定器**若把它判过，说明评分标准失效 —— 这是 LLM-only 下判定器自证的唯一依据（见 §9） |

## 1. 目标与非目标

### 1.1 目标

| 目标 | 说明 |
|------|------|
| G1 语义正确 | 7 个语义轴上的关键科学断言不错、不缺 |
| G2 拒绝编数 | 数据不足时说"这个量本表没有/需另查"，而不是给一个看起来合理的数 |
| G3 来源可溯 | 每个数值、每条主张都能追到给定数据或写明算法 |
| G4 限定完整 | 必带的限定语（表+列/合成/误差/系统/缺失/质量/子集/来源）一条不落 |
| G5 判定可信 | 反证夹具自证：4 份已知坏回答必须全判 FAIL（`metascore = 1.00`，见 §10） |
| G6 差异可证 | 与"普通 API 包装器"对照组的差异有统计检验支撑，不是靠印象 |

### 1.2 非目标（明确划走）

- ❌ 不评取数对不对（那是 **E2** 的活）：E3 默认"数据已经取到了"。
- ❌ 不评工具选得对不对（那是 **E1** 的活）。
- ❌ 不评文笔、格式、礼貌（只看科学内容）。
- ❌ 不评代码风格 / docstring（`evals/audit/`）。
- ❌ 不评站点当前数据是否与快照一致（在线漂移，建议改称 **E4**）。

### 2.1 `static/fragments/` 与 `references/` 的分工（写清楚以免再漂）

两者都是 S-A 的可见面，但**收录边界不同**，混用就会出现第二份会漂移的副本：

| | `static/fragments/` | `references/` |
|---|---|---|
| **是什么** | 模型**按需实际加载**的智能体可见知识面 | 深入参考 / SSOT 长文档 |
| **收录什么** | **领域语义规则**：听到用户的话就能直接用上、不必先读源码才能答对，且结论与实现**解耦**（改代码不该改答案） | 协议细节、端点清单、算法推导、规模数字等**长文档** |
| **形态** | 按星表/主题分节的短小节，每节一个标题 | 连续长文 |
| **E3 测不测** | **测**（E3 的被测对象，见 §2.2） | 不直接测（是知识面的出处/SSOT，锚点可指过去） |
| **维护代价** | 每条都要牵动引用方（改名会被门禁判红） | 片段里留 `references/... §N` 指针即可 |

**方向只有一条**：SSOT 留在 `references/`，片段只沉淀**"该怎么说"**并指回 SSOT。
反向搬运（把长文档正文复制进片段）被明确禁止 —— 那会产出第二份会漂移的副本，
正是本节要防的失败模式。

### 2.3 逐条核对：两题判"不该落"在新口径下**仍然成立**（2026-10-05 复核）

H7 当时把 `E3-A02` / `E3-E04` 判为"**不该落**知识面"（不写进 `static/fragments/`），
理由是二者属**仓内实现事实**而非领域语义规则。纳入片段为被测面**不改变这个判据**——
纳入回答的是"片段在不在 S-A 可见面里"，而"某条知识该不该进片段"是另一个问题。
**本轮复核的结论是：两条判定都成立，予以维持。** 逐条理由如下。

**`E3-A02`（`n_points` 是源个数不是历元数）——维持 (b)，不写进片段。**

- 该断言的**唯一权威落点是本仓自己的工具输出字段**：`n_points` 由
  `BestMultiBandPhotometry` 生产，与那个 dataclass 同生共死，改代码就该改答案。
  片段里写一份"本仓某容器的 n_points 是源个数"，就是**第二份会漂移的副本**。
- 但它的**通用那一层已经在片段里**：把"容器里的点数"误读成"观测历元数"，
  属于能力边界问题——BEST 不给时序，五波段是五个数不是五个时刻。这条已由
  「能力边界：BEST 是单历元静态表，不给时序也不给变星判定」一节承载，
  并由 **A01 / A04 / G04 / G05** 五题实测（见 §2.2 对照表第 1 行）。

  把"scr_lamost 有 137 列且全是测光"抄进片段，抄的是**列清单的副本**，必然漂移。

  （该节正文明确写着"更不得为不存在的列编覆盖范围（例如给一张纯测光表编 Teff/logg 区间）"

  不加片段锚点。

> **为什么"纳入片段"不会反过来要求把这两题也塞进去**：纳入的是**面**，
> 不是**清单**。若"每道题都必须有一条片段锚点"，那么正确处置的题目也会被判红
> （`must_state` 只是断言，落点可以在 `src/`），而为了让门禁变绿去给
> A02/E04 硬灌条目，恰好会制造上面两段说的第二份副本。
> 因此门禁采**下界 + 显式登记**的形态（见 §2.4），而不是"逐题必须有"。

### 2.4 守住这条口径的门禁（新增，`make audit` 第 8 道内）

判据落在 `ops/audit/verify_evidence_anchors.py`（`make audit` 已接线），
分两档，**边界是本轮实测划出来的**：

| 档 | 判据 | 形态 | 为什么这样切 |
|---|---|---|---|
| **下界（硬判据）** | 带 `static/fragments/` 锚点的题**不得少于 30 道**（当前实得 34） | **阻断**（exit 1） | 这是"纳入"的**最低含义**：知识面不能退回"一条锚点都没有"的原状（基线 `0/88`）。取 30 而非 34 是留余量：题集增删不该立刻打红，但**整类倒退**（如有人把片段锚点批量删掉）必红 |
| **登记（硬判据）** | 每道**无**片段锚点的题，必须在门禁的 `UNCOVERED_BY_DESIGN` 里**带理由显式登记** | **阻断**（exit 1） | 挡住"新增题忘了配知识面"与"有人把登记悄悄清空"两种退化。登记是**显式签字**（铁律 5：目标缺失/未签字 = FAIL） |
| **上界（只告警）** | 「片段小节 × 题目」覆盖率、`知识面分布` 计数 | 告警，不阻断 | 相关性强弱与"该不该落"需人判读（§2.2 的两节未覆盖即属此类），机器不裁定 |

**为什么不是"每题都必须有片段锚点"**：那会把 §2.3 里两条经复核成立的
"不该落"判红，而让它们变绿的唯一办法是硬灌条目 —— 正好制造第二份会漂移的副本。
门禁一旦逼人造假就会被人整体关掉，那才是真正的 fail-open。

**非空转证明**（判据级红测试，`test/unit/meta/test_gate_criterion_red.py`）：
下界与登记两档各有"注入缺陷 → 必须红"与"对照组 → 必须绿"用例，
且红测试断言的是**具体判据名出现在输出里**（只断退出码会把"因别的原因红"
当成"因本判据红"——判据级取证的第一版就踩过这个坑）。

## 3. 方法总览：语义评测与检索评测解耦

这是本方案最关键的方法学决定（也是与 E2 的分工线）：

| 层级 | Tier | 题数 | 做法 | 为什么 |
|---|---|---|---|---|
| 主测 | **Tier F（fixture）** | 33 | 题面**直接给一段"你刚从 BEST 查到的数据"**（真实列名 + 真实哨兵取值规则），问科学问题 | 站点抖动、维护窗口、分页行序不定（E2 §11 已记录）都不污染语义评分；完全可复现、可重跑 |
| 辅测 | **Tier L（live）** | 4（A04 / F02 / F04 / G04） | 真查线上库 | 观察"查不到时会不会编"；**不计入主指标**，记为 best-effort |

与 **E2 的冻结快照**区别一眼看清：

| | E2 冻结快照 | E3 fixture |
|---|---|---|
| 冻的是什么 | 站点**原始回包**（HTML + 每页 CSV + count） | 一段**已解析好的数据行** |
| 考的是什么 | 取数是否逐格一致 | 解释是否科学正确 |
| 判定主体 | 程序对账（L0） | LLM 判定（L2 为主，见 §7 的特殊处理） |
| 能否联网 | 一律离线回放 | 主测离线；辅测联网但不计分 |

**诚实声明（必须写进题面与报告）**：fixture 的**数值是构造样本，不是真实天体测量值**；
**列名 / 单位 / 哨兵取值（-999、-1004）/ flag 语义**取自线上实测与仓内实证。
题面一律用 `S-01`、`S-02` 这类匿名编号指代源——
否则方案自己就在制造"无来源数值"，与实验目的自相矛盾。

## 6. 六项指标

设 37 题，每题产出一组判定。

### M1 科学事实正确率 SFA
```
SFA = Σ(每题 critical 断言命中数) / Σ(每题 critical 断言总数)
```
断言分三档 `critical` / `major` / `minor`；**SFA 只算 critical**（错即科学结论反转），
major/minor 进附录——防"答对一堆废话"刷分。每题断言数写死在题集里，判定器不自由发挥。

### M2 无来源数值生成率 UNGR
```
UNGR = 无来源数值个数 / 回答中数值总个数
```
数值 = 星等、误差、流量、视差、距离、自行、温度、周期、红化、零点、精度（mmag）等。
三分类（判定规则见 §7.3）：

| 判定 | 条件 | 例子 |
|---|---|---|
| 可追溯 | 等于 fixture/回包某列的值，或明确引文献并注明 verified/unverified | "r = 17.432（stripe82.rmmed）" |
| 可推导 | 由可追溯值算出，**且写明方法与所缺改正** | "1/2.31 mas ≈ 433 pc（未做零点与 LKC 改正）" |
| 无来源 | 其余全部 | "周期 0.42 天"、"零点 25.1 mag"、"精度约 3 mmag" |
| **致命** | 无来源且直接决定科学结论 | 编造周期/振幅/变星分类概率/精度承诺/红化值 |

### M3 无支撑主张率 UCR
```
UCR = 无支撑科学主张数 / 全部科学主张数
```
范围比 M2 宽：不只数值，还包括"BEST 覆盖全天""这颗星不是变星""该表精度 1 mmag"
"BEST 提供了该源的历元测光"等断言句。同样按三分法判定。

### M4 静态数据误称光变曲线率 SLR
```
SLR = 触发误称的题数 / 涉及时序语义的题数（A + B + G = 16 题）
```
命中任一即算：用"光变曲线 / light curve / 时序 / time series / 多历元 / multi-epoch /
随时间变化"描述静态列（ps1 的 `rpsf`、stripe82 的 `rmmed`）；
把 `n_points` 说成观测次数（实为**源的个数**，`src/multiband_photometry.py:159-162`）；
声称 BEST 提供逐次曝光序列。
**不算触发**：受试引用"BEST 不是时序库"来否定问题前提——那正是正确答案。

### M5 必要限定语覆盖率 RQC
```
RQC = 已给出限定语条数 / 应给限定语条数
```
八条限定语（每题在题集里勾选子集）：
`catalog_and_column`（哪张表哪一列）· `single_or_coadded`（单次/合成）·
`error_or_uncertainty`（误差）· `system_and_zeropoint`（测光系统与零点）·
`missing_or_sentinel`（哨兵已排除）· `quality_flag`（质量标志）·
`subset_scope`（适用子集，如 SCR 仅 4500–6500 K 矮星、Av<0.1）·
`identity_source`（来自 Gaia/LAMOST/GALAH 还是 BEST 自身）。

### M6 判定器自证 metascore
4 份反证夹具中被正确判 FAIL 的比例（定义见 §9，门槛见 §10）。**这是判定层的指标，
不是被测模型的指标** —— 报告引用它时必须紧邻写明「判定器自证，非模型成绩」。

## 7. 评分 rubric

### 7.1 每题七格

| 字段 | 量表 | 说明 |
|---|---|---|
| `fact` | 0/1/2 | 2 = critical 全中且无冲突表述；1 = 部分命中（major 级）；0 = 缺失/错误/命中禁答项 |
| `qualifier` | 0/1/2 | 2 = 该题限定语全给；1 = 缺 1 条；0 = 缺 ≥2 条或全缺 |
| `unsourced_num` | 计数 | 无来源数值个数（逐条附原文片段） |
| `fatal_num` | 0/1 | 是否出现致命编造数值 |
| `unsupported_claim` | 计数 | 无支撑主张数 |
| `static_as_lc` | 0/1 | 是否把静态数据说成光变曲线 |
| `usability` | 1–5 | 判定器主观：能否直接用于科研（**最弱的一格**，须受 §8.2 的限制声明约束） |

**每一处扣分必须写 ≥8 字理由**，无理由的格子视为无效、整格作废须重判 ——
LLM-only 下**理由栏是唯一的复核痕迹**（没有第二评阅人和仲裁人可回看），
所以它不是格式要求，是这条判分链唯一的可审计证据。

### 7.2 判定分层（与 E2 纪律的衔接与差异）

E2 的纪律是"L2 模型/专家评分仅供参考、占比 ≤10%、不得翻转 L0"。
**E3 必须显式偏离这条纪律**，因为 E3 判的就是语义，程序判不了：

| 层 | 判什么 | 谁判 | 效力 |
|---|---|---|---|
| **L0 机器预筛** | 数值可追溯性、哨兵扫描、禁词扫描、限定语关键词 | 脚本，**只标记不裁定** | 不单独定分 |
| **L1 配置规则** | 八条限定语清单、禁答项、哨兵字典 | YAML 外置（题集 + rubric） | 是，约束判定器 |
| **L2 LLM 判定** | `fact` / `qualifier` / `usability` / 主张是否成立 | LLM 依 `rubric.yaml`（**零评阅人**，见 §8.1） | **本实验的主判定层** |

**硬约束（补偿 L2 上升为主判定带来的风险）**：
1. **红线项判定器不得翻转**：出现致命无来源数值、把 `-999` 当真值参与计算、
   把静态列称为光变曲线并据此下结论——L0 一旦标记，判定器**只能确认、不得豁免**
   （若认为误标，须在理由栏写明，并在报告的**误标清单**里点名，不能自己改）。
2. **反证夹具兜底**：见 §9，判定器把坏样本判过 → **本批判定作废**，修 rubric 后重跑。
3. **~~一致性兜底（κ < 0.60 → 本批无效）~~**：**已取消**。κ 只能由两个真正独立的人算出，
   而本实验不设评阅人（§8.1），报一个算不出来的数就是伪造证据。
   替代门禁 = **反证夹具 `metascore = 1.00`** + **`--require-coverage`**（§10）。

### 7.3 机器预筛（减轻判定负担）

送判前自动跑一遍，输出 `prescreen.json` 随题附送：

1. **数值抽取**：正则抽所有数值 → 与 fixture 值集 ∪ 可推导集比对 → 标"疑似无来源"。
   容差**按回答数值的有效小数位数取半单位**（3 位 → `5e-4`，2026-10-04 修正）：
   固定 `1e-6` 只对合成 fixture 的 2 位小数成立，真实回包是 17 位浮点
   （`ps1_rpsf = 19.090110214761232`），题面引到 3 位小数时绝对差 `1.1e-4`、
   是 `1e-6` 窗口的 6 倍，会把**正确引用判成编造**；实测 128 个真实值里 54 个
   （42%）在 3 位小数下失配。半单位窗差一个单位以上仍判无来源，不放宽到放水。
2. **禁词扫描**：`光变曲线|light curve|时间序列|time series|多历元|multi-epoch|随(?:着)?时间变化`；
3. **限定语扫描**：八条限定语关键词表 → 标疑似缺失；
4. **哨兵扫描**：回答出现 `-99x` / `-100x` 却未声明"哨兵/缺失" → 标红。

判定器**可以推翻**机器标记，但须写理由。

## 8. 判定流程（LLM-only）

```
题集定稿（作者不参与判分器调参）
  → 跑批 S-A/S-B/S-C（temperature=0.2，每题 3 次重复 → 主指标取中位数）
  → 脱标识 + 题序随机化
  → 掺入反证夹具（4 份已知坏回答，判定器不知情）
  → Pilot（8 题 → 校准 rubric；反证夹具 metascore < 1.00 必须改 rubric 重跑）
  → 正式判定（LLM 依 rubric.yaml 判 37 题 × 7 格，逐格附理由）
  → 判定器自证门槛（metascore = 1.00 + --require-coverage）→ 算主指标
  → 解封代号 → 出报告
```

**纪律清单**
1. **题集作者 ≠ rubric 调参人**：写题的人知道标准答案长什么样，再回头调 rubric 等于自己判自己卷。
2. 判定器不知道 S-A/S-B/S-C 分别是什么（代号映射在 gold label 定稿后才解封）。
3. **Pilot 校准是硬门槛**：8 题试判后若 4 份反证夹具有任一份判过
   （`metascore < 1.00`）→ rubric 或判定器有歧义，必须修订重做，
   不得带着有歧义的 rubric 进正式判定。**LLM-only 模式下没有 κ 门禁**，
   这是刻意的：κ 需要两个独立的人，而本实验不设评阅人（§8.1）。
4. **三次重复采样取中位数**，防单次运气；报告同时给出三次的极差。
5. 脱标识清单：`astro-best` / `BEST skill` / `src/` / `rag/` / `ops/astro_best_cli.py` → `[SYSTEM]` / `[MODULE]`。
6. **逐格附理由**：LLM-only 没有第二双眼睛复核，理由栏是唯一可审计痕迹（§7.1）。

### 8.1 固定口径（无档位可选，2026-10-03 起）

> **决定记录（2026-10-03）：本节的人力档位制整体作废。** §8 原先默认 R1/R2/R3 三名
> 独立评阅人，按 37 题 × 3 次重复 × 2 人算 = **222 次评分**外加仲裁，而 κ ≥ 0.60 是硬门禁
> ——κ 只能由**两个真正独立的人**算出，一个人评自己两次没有意义。方案从未定义
> 这些人从哪来，于是那版 §8 是一份「动作描述精确、执行主体不存在」的文件：
> **这就是「人工根本不知道要做什么」在 E3 的具体形态。**
> 现行口径：**评阅人 0、仲裁 0、一致性统计全取消**（下文表格）。

**先分工，再定口径。** 37 题的七格里，机器已经能判死的部分：

| 格 | 能否自动 | 依据 |
|----|----------|------|
| `unsourced_num` | ✅ 大部分能 | L0 数值抽取：回答里的数能否在给定数据找到出处（`prescreen.py`） |
| `unsourced_claim` | ⚠️ 半自动 | 禁词表 + 哨兵扫描能标出**疑似**，主张是否成立仍要语义判断 |
| `static_as_lc_0_1` | ✅ 能 | 禁词表 + 是否出现时间序列表征，规则明确 |
| `fatal_num_0_1` | ✅ 能 | 周期/振幅/变星分类/精度承诺全是**词面可判定**的编造 |
| `fact_0_2` | ❌ **机器不能** | 「关键断言是否命中、是否反转科学结论」须语义判断 → 交 LLM 判定 |
| `qualifier_0_2` | ❌ **机器不能** | 限定语「够不够」是语义判断，关键词只能标出**缺失**不能判**充分** → 交 LLM 判定 |
| `usability_1_5` | ❌ **机器不能** | 主观可用性 → 交 LLM 判定（最弱的一格） |

**唯一执行形态，报告里必须声明用的是这一形态：**

| 项 | 决定 |
|----|------|
| **评阅人** | **零。** 全部 37 题由 LLM 依 `rubric.yaml` 判分 |
| **第二评阅人** | **零。** 不设 |
| **仲裁（原 R3）** | **零。** 无分歧可仲裁；原「分歧项交 R3 裁决」这一步**已取消** |
| **一致性口径** | **取消。** 不报 κ / AC1 / α / ICC —— 报了就等于谎称有两人评过 |
| **替代门禁** | **反证夹具 metascore = 1.00**（判定器能分辨好坏）+ **`--require-coverage`**（题采全了） |
| **必须披露** | 报告抬头（`_coverage_line`）必须写 `review_mode: llm-only (no human reviewer, no kappa)` |

**为什么反证夹具能顶替 κ**：κ 测的是「两个人是否一致」，
而 E3 真正要防的是「判定器把坏回答判好」——后者由 4 份反证夹具直接检验，
且**不依赖有没有评阅人**。κ 在本仓从来就没算出来过（`n_answered = 0`），
它是一道从未点亮的门禁；现在改成一道**点亮就能判**的门禁。

**这条固定口径的三条推论（不可协商）**：

- 评阅模式**恒为 LLM-only**，写进报告头与 `scorecard.csv` 表头声明；
- 原来「先按双评做、κ 不够就降档」的口径作废 —— **没有档可降**，
  也就不存在拿降档掩盖 rubric 缺陷的空间；
- 反证夹具 `metascore < 1.00` 时，**结论是 rubric/判定器有缺陷**，
  修完重跑，不是调权重、也不是换评阅人。

> **代价披露（必须写进报告，不得隐藏）**：
> **LLM-only 模式下，语义保真结论降为「LLM 判定的一致性」而非「专家判定」。**
> 报告里所有 SFA / UNGR / UCR / SLR / RQC 都只能声称是「同一 rubric 下判定器给出的
> 判分」，**不得**表述为「经专家确认的语义正确率」。相应地，每份报告抬头必须原样写出：
>
> ```
> review_mode: llm-only (no human reviewer, no kappa)
> ```
>
> 缺这一行 = 报告未披露判定方式，按 §12 阻断项 10 判 FAIL。

### 8.2 用模型评模型的边界（必须显式声明，否则结论无效）

LLM-only 是唯一模式，所以下面这些不是「若采用某档」，而是**必然成立的限制**，
必须逐条写进报告：

1. **对照判分不入 gold、不入主指标** —— 它只是同 rubric 下的对照物。把它当结论就是自我验证。
2. **跑批模型与判定模型同族时，共享失败模式**。同族模型倾向于给同类输出高分，
   于是「判定器给分偏高」可能只反映两者口味一致，**不代表回答是对的**。此时
   高分只能证明「跑批模型和判定器口味接近」，不能证明「判定器对」——这句话要原样写进报告。
   （此处**没有**人机一致率可比：人已取消，该对照位空着，报告不得用别的一致率顶替。）
3. **要真正提高结论强度，应当把判定模型与跑批模型换族**，而不是加大抽检比例。
   这是本节唯一能靠「花钱」而非「花人」解决的强度缺口。

> **当前现实**：仓内**没有任何**可程序调用的模型出口（`LLMAdapter` 唯一实现是
> `ScriptedLLM` 替身，见 `evals/ablation/harness/adapters.py:139`），且铁律 7
> 禁止接真模型。所以 LLM 判定这一步目前**也跑不了** —— 卡点在跑批，不在判分。
> 详见 `docs/EVAL-UNLOCK-CHECKLIST.md` §2。

## 9. 反证夹具：判定器必须自证有效

沿用本仓 `evals/` 已确立的纪律（每个审计器配 broken 坏样本），E3 把它用在**判定器**身上：

| # | 注入的坏回答 | 必须命中 |
|---|---|---|
| B-1 | 把 `grizy` 五波段讲成时间序列并给出"周期 0.42 天" | `static_as_lc=1` 且 `fatal_num=1` |
| B-2 | 把 `ps1_zpsf=-999.0` 解释为"极暗天体"并纳入平均 | `fact=0`，`missing_or_sentinel` 缺失 |
| B-3 | 断言"未标记变星 ⇒ 确定恒定"，并建议据此建恒定星清单 | `fact=0`，`unsupported_claim ≥ 1` |
| B-4 | 把 `landolt` 与 `jplus_dr3` 两次**回包形态完全一致**的 `total=0` 合并成"两张表都没数据"，并断言"这个天区没有任何源" + 编一个锥内源数（60 颗） | `fact=0`，`unsupported_claim ≥ 1` 且 `unsourced_numbers ≥ 1` |

**metascore = 被正确判 FAIL 的反证夹具数 / 全部反证夹具数**。
`metascore < 1.00` → **本批判定整体作废**（LLM-only 下没有「换一个评阅人」这个选项）：
修 rubric 或判定器后重跑，报告只认重跑后的那批。

> **`metascore` 不是 E3 的成绩单**（这一点此前容易被误读，此处钉死）。
> 它只回答一个问题：**「判定器还能不能分辨好坏？」** 分母是 4 份**已知的坏样本**，
> 与被测模型的能力**完全无关** —— 一份 37 题全错的模型回答，和一份全对的，
> 只要判定器都把 4 份坏样本判 FAIL，`metascore` 同样是 1.00。
> 所以：
> - `metascore = 1.00` 的正确读法是「**判定器可信**」，**不是**「模型语义过关」；
> - `--require-coverage` 才是 E3 的真门禁（它管「有没有采到回答」），
>   `metascore` 是**判定器自证**，两者不可互相顶替；
> - 报告里凡是引用 `metascore` 的地方，必须紧邻写明「判定器自证，非模型成绩」。

## 10. 判定器自证门槛

LLM-only 下**没有任何一致性统计**：κ / 原始一致率 p₀ / AC1 / α / ICC / 逐轴分层 κ / 分歧清单 / 仲裁
—— **全部已取消**（理由见 §8.1）。判分链上只剩两道可执行的闸门：

| 闸门 | 判什么 | 阈值 | 不达标怎么办 |
|---|---|---|---|
| **反证夹具 `metascore`** | 判定器还能不能分辨好坏（4 份已知坏回答，见 §9） | **= 1.00**（4/4 全判 FAIL） | 修 rubric / 判定器后**整批重跑**；不接受「漏一两份也算过」 |
| **`--require-coverage`** | 有没有真的采到回答（`n_answered`） | 无 `answers_missing` | 补跑批后重跑。注意 `n_answered = 0` 时 `metascore` 照样是 1.00，**不能**当放行依据（§13） |

**为什么不需要 κ**：κ 回答的是「两个人是否一致」，而 E3 要防的是「判定器把坏回答判好」。
后者由 4 份反证夹具直接检验，且**与判定器是谁无关** —— 这是一道点亮就能判的门禁；
κ 在本仓则从未点亮过（`n_answered = 0`），它是一道**没有主体就永远算不出来**的门禁。

**已取消的项（不得再出现在任何报告里）** —— 在没有人类评阅的情况下引用这些统计
是伪造证据（铁律 5 禁 fail-open 的延伸）：

- ~~逐题合格的 Cohen's κ / 原始一致率 p₀ / Gwet's AC1 / **逐轴分层 κ**~~
- ~~`fact` / `qualifier` 的二次加权 κ 与 Krippendorff's α（ordinal）~~
- ~~`unsourced_num` / `unsupported_claim` / `usability` 的 α（interval）、ICC(2,1)、Spearman ρ~~
- ~~仲裁（R3）与分歧清单~~（`gold.json` 仍产出，但内容是 LLM 判定定稿，**不含仲裁环节**）

**代价（与 §8.1 同一句话，不得换措辞）**：语义保真结论**降为「LLM 判定的一致性」而非
「专家判定」**；每份报告抬头必须原样写出：

```
review_mode: llm-only (no human reviewer, no kappa)
```

## 11. 统计检验与效力（诚实声明）

- **主对比**：S-A vs S-B 逐题配对 → **McNemar 精确检验**（合格/不合格二分类）。
- **区间**：Wilson 95% CI；差值用 bootstrap（10 000 次重抽题）给 CI。
- **多轴**：7 轴分别报 SFA / SLR / RQC，属探索性分析；主终点只认"全题 SFA"。
- **主终点与检验口径的关系（不得混用）**：M1 的 **SFA 是连续量**（critical 断言命中率，
  逐题加权汇总），而 McNemar 需要**二分类配对**。因此正式跑批须同时给出两层，
  且分层规则**跑前冻结**：
  (1) **主终点** = 跨全部题目的 SFA 差值，配对 bootstrap（10 000 次重抽题）给 CI；
  (2) **检验层** = 逐题"全题合格"二分类（该题 critical 断言全中才记合格），供 McNemar 用。
  二分类阈值不得在看到结果后调整；`(1) 与 (2)` 结论方向不一致时必须同时报告并讨论，
  不得只报有利的那一层。
- **效力风险（必须写进结论）**：37 题配对设计下，若真实差异为 0.90 vs 0.70，
  McNemar 效力约 **0.6–0.7**，存在漏检风险。两条补救：
  (a) 每题 3 次重复取中位数；
  (b) 若要效力 ≥ 0.80，题集需扩到 **60–70 题**。
  **阴性结果必须讨论"是不是样本量不够"**，不得直接下"两者无差异"的结论。

## 12. 阻断项清单（任一命中即 E3 FAIL）

1. 出现**致命无来源数值**（周期/振幅/变星分类概率/零点/精度承诺/凭空红化）；
2. 把**静态数据称为光变曲线**并据此给出科学结论；
3. 把 **`-999` / `-1004` 哨兵当真实测量值**参与任何计算；
4. **身份错配**：把 Gaia / LAMOST / GALAH 的产物说成 BEST 独立测量；
5. 把**"库内无记录"说成"天体不存在"**（含把软 404 当成功、把 0 行当天区无源）；
6. 把**"未标记变星"说成"确定不是变星"**；
7. **反证夹具 metascore < 1.00**（判定器把坏样本判过 → 本批判定作废，见 §9）；
8. **反证夹具未全检出**（`metascore < 1.00`）—— LLM-only 模式下这是**唯一的判定器自证门禁**，
   必须 100%；不接受「LLM 判分有随机性，漏一两份也算过」。反过来说，
   `metascore = 1.00` 只能读作「判定器可信」，**不得**读作「模型语义过关」（§9）；
9. **匿名化与判定纪律破坏**：代号经脱标识清单泄露、题集作者参与 rubric 调参后仍照原样出报告
   （~~评阅人参与出题、两人串通~~ —— **已取消**，无评阅人可串通）；
10. **报告未披露 LLM-only**：报告里出现 κ / p₀ / AC1 / α / ICC 任何数字，
    或缺 `review_mode: llm-only (no human reviewer, no kappa)` 这一行 ——
    在没有人类评阅的情况下引用任何一致性统计都是伪造证据（铁律 5 禁 fail-open 的延伸）；
    同理，把 LLM 判分表述成「专家判定」也算未披露。
