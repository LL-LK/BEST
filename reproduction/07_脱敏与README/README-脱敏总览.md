## 五、已知边界

1. **本包支持证据核验与分析重算**，不支持在无原环境下完整重跑；
2. 完整重跑需要 Harness 安装包、真实模型凭据、隔离 Windows 身份、WSL/bubblewrap 等，**这些不随包分发**；
3. 哈希已按脱敏后内容重算，包内自洽；与原批次的哈希**不可直接比对**；
4. E3 的「教师反馈」目录（含外部审阅者痕迹）**未纳入**最小包；
5. E5 的两个 `-before-` 中间备份 zip 已按「最小」原则剔除，仅保留最终版。
