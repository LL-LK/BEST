# 替换规则表 REPLACEMENT-RULES

本表为逐轮苏格拉底对齐后形成的最终执行依据，全流程唯一口径。**匹配模式已打码**；含完整原值的版本不随包分发。

## 一、方向性决定

| 议题 | 结论 |
|---|---|
| 脱敏边界 | E1–E6 + 复现必需源码 |
| 「最小」标准 | 以包内已声明的「复现必检文件」为准 |
| 包结构 | 六个独立 zip，再套一层总 zip |
| 改动方式 | 复制另存，原件零改动 |
| 哈希冲突 | 按脱敏后内容重算 + 显式声明 |
| 对外承诺值 | 保留原值 + 标注不可直接比对 |
| 嵌套归档 | 全部解开脱敏后重打包 |
| `__pycache__` | 排除（.pyc 把源码绝对路径烧进字节码） |
| E5 执行过程 | 纳入 |
| 映射表泄露 | 包内打码，原值版留包外 |
