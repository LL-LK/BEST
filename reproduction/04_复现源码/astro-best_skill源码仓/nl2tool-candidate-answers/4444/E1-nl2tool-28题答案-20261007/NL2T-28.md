# NL2T-28

## 用户原话
> 在 RA=180.0、Dec=30.0、半径 60″ 内查一下 2MASS 的 J 波段星等。

## 判定
拒绝（不给调用）—— BEST 星表注册表里根本没有 2MASS 这张表，也没有近红外 J 波段（1.25 µm）星等；任何 `cone_search` 都会落到不存在的表 / 不存在的波段上，故不发起取数调用，改为说明能力边界并给替代选项。

## 期望调用

## 参数与换算
逐参数给出「如果这个请求成立本该怎么传」，以及它为何在本题不成立：

- `ra=180.0`：单位已是**度**，ICRS 天球坐标，落在合法值域 `[0, 360)`（`build_query_form` 校验 `0.0 <= ra < 360.0`）。**无需换算**。BEST 口径即度（`describe_catalog` 的 `units_note`："ra/dec in degrees"）。
- `dec=30.0`：单位**度**，落在合法值域 `[-90, 90]`。**无需换算**。
- `radius 60″`：单位是**角秒**，直接对应工具参数 `cone_search(radius_arcsec=60.0)`，也对应表单键 `pos.radius`（角秒口径），**不换算**。
  - 单位陷阱（skill 高频出错点）：`BestQuery.cone(ra, dec, radius_deg)` 用的是**度**口径；若走那条链式构造器，60″ 必须换算 `60 / 3600 = 0.016666...°`。工具面 `cone_search` 用角秒，两者不可混（`static/fragments/target_type/photometry_region.md` 明确要求「deg/arcsec 差异必须双处断言」）。
- `catalog`：用户要 **2MASS**。`resolve_catalog("2mass")` 在 `CATALOG_PATHS`（12 张表）里查不到，也不在 `CATALOG_ALIASES`（唯一别名只有 `gaia_dr3 -> gaia_dr3_18`），抛出 `ValueError` → 映射为 `E_INVALID_INPUT`。**BEST 无可填的 catalog 值**。
- `columns / band`：用户要 **J 波段**。`CATALOG_MAG_COLUMNS` 里**没有任何一张表发布近红外 J**（1.25 µm）。最接近近红外的只有 `ps1` 的 **y 波段**（`ps1_ypsf`，≈0.96 µm）；`jplus_dr3 / uss_dr1 / splus_dr4 / scr_galah / scr_lamost / xpsp` 里出现的 `j0378/j0395/…/j0861` 是 **J-PAS / J-PLUS 的光学窄带**，`jkc_*` 是 **Javalambre（JKC）U/B/V/R/I** 光学系统 —— 二者名字里的「J」都不是 2MASS 的近红外 J。**没有任何 columns/band 取值能满足该请求**。

## 陷阱与错法
- **把「J」误当成 J-PAS / J-PLUS 的窄带**（`j0378…j0861`、`jpas_j0xxx`、`jplus_j0xxx`）：那些是 **Javalambre** 的光学窄带（≤1.007 µm），名字里的 J 来自巡天名而非 2MASS 近红外 J（1.25 µm）。**波段语义完全不同，不能替代。**
- **把 JKC 的 `jkc_*` 当成近红外**：JKC = U/B/V/R/I，是光学系统（`photometric-systems.md` §2）。
- **硬编造 catalog / 列名**：传 `catalog="2mass"` 会被 `resolve_catalog` 拒（E_INVALID_INPUT）；若绕过注册表硬拼 `showcol` 的 `j_mag/jmag` 一类**幻影列**，站点会**静默丢弃未知 showcol 键**，返回全表或空表 —— 调用方读成「这片天区没有源」，是比报错危险得多的静默错答（`qualify_column` 的 fail-closed 正是为挡这个）。
- **半径单位错**：把 `60″` 当 `60`（度）传进 `BestQuery.cone` 口径，或把 60 当角秒传给度口径接口，锥大小差 3600 倍。
- **拿 `ps1` 的 y 波段冒充 2MASS J 而不声明**：PS1 y（≈0.96 µm）与 2MASS J（≈1.25 µm）是**不同测光系统、不同零点、不同波长**，数值不可互当（`best_catalogs.md`「跨表星等不能直接相减」段）。
- **把 0 行读成「该天体不存在」**：即使换成现有表，60″ 小锥在 `landolt`（约 1 行/3.7 deg²）一类表上期望命中极低，0 属统计正常；结论必须带「表 + 半径 + 约束」限定。
