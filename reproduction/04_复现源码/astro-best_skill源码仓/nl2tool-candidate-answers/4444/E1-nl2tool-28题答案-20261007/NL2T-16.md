# NL2T-16

## 用户原话
> 在 RA=180.0、Dec=30.0、半径 60″ 内，要 S-PLUS 的 r 波段星等。

## 判定
直接调用 —— 坐标/半径/目标波段全部齐备且无歧义，S-PLUS 唯一可查询 id 与 r 波段列名均已在本地注册表内定死，可直接发一次锥形检索。

## 期望调用
```python
toolbox.cone_search(
    ra=180.0,
    dec=30.0,
    radius_arcsec=60.0,
    catalog="splus_dr4",
    columns=["splus_dr4_r_pstotal"],
)
```

## 参数与换算
- **ra=180.0**：原值直接传入。skill 口径 ra/dec 单位就是**度**（ICRS），落在合法区间 `[0, 360)`，无需换算。
- **dec=30.0**：原值直接传入，落在合法区间 `[-90, 90]`。
- **radius_arcsec=60.0**：用户给的「60″」即 **60 角秒**，与工具 `radius_arcsec` 的单位（角秒）**逐位一致，不需要换算**（1″ = 1 角秒）；校验要求 `>0 且 ≤18000`，60 通过。
- **catalog="splus_dr4"**：BEST 注册表里 S-PLUS 的唯一可查询 id（`CATALOG_PATHS` 键 `splus_dr4` → 路由 `splus_dr4/q`；`CATALOG_DISPLAY["splus_dr4"] = "Well-Calibrated S-PLUS DR4"`）。必须是**裸 id**，`/q` 只接受裸星表 id。
- **columns=["splus_dr4_r_pstotal"]**：r 波段星等列。`CATALOG_MAG_COLUMNS["splus_dr4"]` 里键 `r_pstotal` → 波段标签 `"r"`，即 S-PLUS 的 r 波段星等 = `{band}_pstotal`（点源总星等）那一族，响应列全名为 `splus_dr4_r_pstotal`。
  - **列名前缀规则**：该星表单表结构（`CATALOG_FORM_TABLES` 未登记多表 → `catalog_tables()` 返回 `("splus_dr4",)`），响应列以表单表名 `splus_dr4_` 为前缀。`qualify_column()` 对三种拼写等价归一为表单键 `splus_dr4.r_pstotal`：裸名 `r_pstotal`、带前缀 `splus_dr4_r_pstotal`、限定名 `splus_dr4.r_pstotal`。本答案给**带前缀全名**，与线上响应列名逐字对齐、最不易误判。
- 其余参数保持缺省：`sort=None`、`order="asc"`、`nearest_only=False`、`max_rows=1000`。用户只要「该锥区内的 r 波段星等」，未要求排序/最近邻/更大行预算，不擅自加参数。

## 关键依据
- `src/protocol_catalog_tables.py`：`CATALOG_PATHS`（`"splus_dr4": "splus_dr4/q"`）、`CATALOG_DISPLAY`（`"splus_dr4": "Well-Calibrated S-PLUS DR4"`）、`CATALOG_COLUMNS["splus_dr4"]`（含 `"splus_dr4_r_pstotal"`）、`CATALOG_MAG_COLUMNS["splus_dr4"]["r_pstotal"] = "r"`。
- `src/protocol.py`：`resolve_catalog()`（裸 id 归一，分组名/未知名显式抛错）、`qualify_column()`（裸名/带前缀/限定名三拼写过同一套逐星表白名单，归一到 `{table}.{col}`）、`build_query_form()`（`show_columns` → 表单 `showcol`）。
- `src/ai_tools.py`：`ToolBox.cone_search(ra, dec, radius_arcsec=180.0, catalog="ps1", columns=None, sort=None, order="asc", nearest_only=False, max_rows=1000)`；`columns` 只做 `list()` 归一，列名合法性交协议层。
- `src/scripts/guards.py`：`validate_search_radius()`（`>0` 且 `≤18000` 角秒）、`validate_coordinate()`（ra∈`[0,360)`，dec∈`[-90,90]`）。
- `references/ALGORITHM-SPEC.md` §7（智能体工具面锚点）；`references/tools.schema.json`（`cone_search.radius_arcsec` 单位角秒、上限 18000）。
- `static/fragments/data_source/best_catalogs.md`（`splus_dr4` 在 12 张可查询表内）；`references/photometric-systems.md`（S-PLUS 波段命名陷阱：`showcol` 投影须用线上表单页的 `{table}.{col}` 全名，不能凭缩写猜）。

## 陷阱与错法
- **catalog 拼错**：写成 `"splus"` / `"S-PLUS"` / `"splus_dr3"` 等 → `resolve_catalog()` 抛 ValueError → 映射 `E_INVALID_INPUT`（本仓 S-PLUS 只有 `splus_dr4` 一个 id，无别名）。
- **catalog 带分组前缀**：`"calib/splus_dr4"` —— `calib` 是导航分组不是表，`/q` 只认裸 id，带前缀路径返回 **HTTP 200 + `{"error":"Not Found"}`** 的软 404，`http_status==200` 门禁看不出来（须并查响应体）。
- **列名靠猜**：猜成 `splus_dr4_rmag`（那是 `landolt` 的命名）、`splus_dr4_rpsf`（`ps1`/`smss_dr4` 的命名）、`splus_dr4_r`（不存在）—— `qualify_column()` 白名单 fail-closed 直接 `E_INVALID_INPUT`；若被绕过则会落到服务端丢弃的幻影表单键上，静默返回全列而非过滤结果。
- **误取改正列**：`splus_dr4_r_corr` 是改正列不是星等列，`CATALOG_MAG_COLUMNS` 故意不收；用它当「r 波段星等」是错答。
- **半径单位错**：把「60″」当成 60 度传 → 实际半径放大 3600 倍，锥检索退化成半张星表并可能触发上限校验；或误当 60 arcmin → 3600″。本题 60 已是角秒，**直接传 60.0，不做任何乘除**。
- **天区覆盖**：`splus_dr4` 只覆盖南天 survey 天区（见 `references/best-database-guide.md`），RA=180.0 / Dec=+30.0 大概率落在其天区外 → **0 行是正常结果，不是故障**，不要据此改参数、换表或报错；也正因如此更不该提前「替用户」拒绝或澄清。
- **误转 astro-catalog**：BEST 自身数据全 ecosystem 只有本 skill 能查，`astro-catalog` 无 BEST 端点，不得外转。
