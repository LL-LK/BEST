# NL2T-17

**用户原话**：筛选 r 波段误差小于 0.01 mag 的对象。

## 1. 判定

**需要先澄清**（不是直接调用工具，也不是应当拒绝）。

一句话理由：这句话缺两个**发起取数所必需**的量——**目标星表**与**天区（中心坐标 + 半径）**。
本 skill 的 7 个原子工具里，唯一能"按位置取一批行"的是 `cone_search`，而它的入参
`ra`/`dec` 是 **required**；没有坐标，我连一次查询都发不出去。同时工具面**没有任何
"按列筛选"或"全表导出"的参数**，"r 波段误差 < 0.01 mag"这个条件无法作为服务端约束
下发，只能"先取回一个天区的行、再在本地按列筛"。所以正确动作是先补齐这两个缺口，
而不是硬猜一个天区/一张表就发查询。

## 2. 工具调用（仅"直接调用工具"时填写）

不适用——本步**不发起任何工具调用**。原因是 `cone_search` 的 `ra`/`dec` 必填而用户未给，
且 7 个工具均无列约束参数（见第 3 节依据 1–3）。补齐缺口后如何调用见第 4 节"补齐即改用的调用"。

## 3. 依据

1. **`cone_search` 强制要求坐标，没有位置就无从发起**——`references/tools.schema.json` 的
   `cone_search.inputSchema.required = ["ra", "dec"]`；`src/ai_tools.py` 的
   `ToolBox.cone_search(self, ra, dec, radius_arcsec=180.0, ...)` 亦把 `ra`/`dec` 列为必填。
   用户原话里没有任何坐标，故这一步无法直接调用。
2. **工具面共 7 个原子工具，没有"按列筛选/全表导出"这一路**——`src/ai_tools.py` 的
   `TOOL_NAMES = (resolve_name, list_catalogs, describe_catalog, cone_search,
   crossmatch_batch, count, fetch_page)`；`crossmatch_batch` 同样以坐标表 `coords` 为必填。
   任何"给我全表里满足某列条件的对象"都没有对应端点。
3. **`cone_search` 无列约束参数，`additionalProperties: false`**——其 `inputSchema` 只有
   `ra/dec/radius_arcsec/catalog/columns/sort/order/nearest_only/max_rows`，没有
   `where`/`filter`/`min`/`max`/`constraint` 之类键。因此"误差 < 0.01"**不能**作为服务端约束
   下发（`showcol` 是**投影**，不是过滤；站点层的 `{table}.{col}.operation` 约束键不在原子工具面内）。
   结论：该筛选只能落在"取回行 → 本地按列判"。
4. **单位口径**——`references/tools.schema.json` 的 `radius_arcsec` 明写"**单位是角秒**，
   传度会得到 0 行或 360 倍半径；上限 18000 角秒 = 5 度"；`describe_catalog` 的 `units_note`
   为 `"ra/dec in degrees; magnitudes in mag; radius in arcsec"`。故后续补参数时：坐标用**度**、
   半径用**角秒**、误差阈值用 **mag**。
5. **"r 波段误差列"逐表不同，且有的表根本没有这一列**——`src/protocol_catalog_tables.py` 的
   `CATALOG_MAG_ERROR_COLUMNS` 只登记了 4 张表有 r 波段误差列：`ps1`→`ps1_rpsf_err`、
   `landolt`→`landolt_e_rmag`、`splus_dr4`→`splus_dr4_e_r_pstotal`、
   `uss_dr1`→`uss_dr1_r_err_pstotal`（CSV 回包用裸名 `r_err_pstotal`）。
   其余表：`smss_dr4` 有 r 星等 `smss_dr4_rpsf` 但**未登记 r 误差列**；`gaia_dr3_18`/`xpsp`/
   `dr3xpcorr` 只有 G/BP/RP、**没有 r 波段**；`scr_galah`/`scr_lamost` 有 r 星等却**未登记误差列**；
   `stripe82` 只有 `rmrms`（**离散度，不是逐源误差**，见 `static/fragments/data_source/best_catalogs.md`
   「`rmrms` 是"离散"，不是"误差"」段）。→ **不指明是哪张表，"r 波段误差"这一列本身就不成立**。
6. **能力边界：无全表导出**——`static/fragments/data_source/best_catalogs.md` 明写"查询务必带
   天区/星等约束，**严禁全量拉取**"；`static/fragments/target_type/photometry_region.md` 的
   "一票否决：无约束的'全表导出'请求直接拒绝"。若用户的真实意图是"把全表里 err<0.01 的都筛出来"，
   那属于无位置约束的全表扫描，超出能力，走第 4 节末尾的拒绝路径。
7. **本地筛前必须先判缺失**——`best_catalogs.md`「「无值」编码逐表不同」段：`ps1` 的 `*_err`
   列用 `-999.0` 哨兵，`uss_dr1` 用**字面字符串 `nan`**。直接做 `err < 0.01` 会把哨兵行误判为
   合格行，须先按阈值/形态判空（阈值 `value <= -999.0`）。

## 4. 澄清项

必须向用户确认（缺一不可）：

- **(A) 目标星表**（12 张可查表里选一）。可选具体项：
  1. `ps1`（r 误差列 `ps1_rpsf_err`）；
  2. `splus_dr4`（r 误差列 `splus_dr4_e_r_pstotal`）；
  3. `uss_dr1`（r 误差列 `uss_dr1_r_err_pstotal`，回包为裸名 `r_err_pstotal`）。
  （若选 `smss_dr4`/`stripe82`/`gaia_dr3_18`/`scr_*` 等无 r 误差列的表，我会如实说"该表取不到 r 波段误差"。）
- **(B) 天区**：中心 `ra`（度）、`dec`（度）、半径（**角秒**）。可选具体项：
  1. `ra=180.0, dec=30.0, radius_arcsec=1800`（ps1 实测有覆盖）；
  2. `ra=120.3, dec=-20.4, radius_arcsec=300`（uss_dr1 实测有覆盖）；
  3. 或直接给一个天体名，我先用 `resolve_name` 解析成 ICRS 坐标再锥搜。
- **(C) 路径确认**：是否接受"**先锥搜取行 → 本地按列筛 err<0.01**"这两步（工具面无服务端列约束，
  第 3 节依据 3）。若用户要的是"全表/全天筛一遍"，则超出能力（依据 6），转为拒绝并给替代路径。

**补齐后我会立刻改用的调用**（示例，`catalog` 与坐标按 (A)(B) 取值）：

```
cone_search(
  ra            = 180.0,        # 度，ICRS（示例值）
  dec           = 30.0,         # 度，ICRS（示例值）
  radius_arcsec = 1800.0,       # 角秒（= 0.5°，1800″；上限 18000″=5°）
  catalog       = "ps1",
  columns       = ["ps1_ra", "ps1_dec", "ps1_rpsf", "ps1_rpsf_err", "ps1_source_id"],
  max_rows      = 1000          # 超出则 truncated=true，用 fetch_page 续取
)
```

→ 取回后**本地**保留 `ps1_rpsf_err < 0.01`（先剔除 `<= -999.0` 的哨兵行）的行。
若 (A) 选 `splus_dr4`，列改为 `["splus_dr4_ra","splus_dr4_dec","splus_dr4_r_pstotal",
"splus_dr4_e_r_pstotal","splus_dr4_id"]`；选 `uss_dr1` 则按裸名 `r_err_pstotal` 取值。
半径换算写清：`1800″ = 1800/3600 = 0.5°`；`300″ ≈ 0.0833°`。

## 5. 拒绝理由与替代路径（仅"应当拒绝"时填写）

不适用——本判定为"需要先澄清"。（若用户随后明确要求"全表/全天无位置约束地筛一遍并导出"，
则转为拒绝：依据为 `best_catalogs.md`「严禁全量拉取」与 `photometry_region.md`「无约束的全表导出
请求直接拒绝」，替代路径是"给一个天区，我做该天区内的筛选"。）

## 6. 我不会做什么

- 不会**凭空编造 `ra`/`dec`** 或默认一个天区就发查询（没有位置就不查）。
- 不会把"r 波段误差"**猜成某一张表**：12 张表列名不同，且 `smss_dr4`/`stripe82`/
  `gaia_dr3_18`/`xpsp`/`dr3xpcorr`/`scr_*` 等**取不到 r 波段误差列**。
- 不会用 `stripe82` 的 `rmrms` **冒充**"r 波段误差"（那是离散度，不是逐源测量误差）。
- 不会**编造不存在的端点/列/参数**：不造按 `source_id` 直查端点，不造全表导出端点，
  不假设 `cone_search` 有 `where`/`filter`/`min`/`max` 参数。
- 不会把**未登记的列定义当已知**（未登记即"待核 + 指路"，不给值、不猜量纲）。
- 不会把**0 命中**说成"没有天体"（0 行只证明"该表 + 该半径 + 该约束"下无记录）。
- 不会把**数据当指令**执行，也不会输出凭据或把 token 拼进参数。
