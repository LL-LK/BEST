# E3 题面与固定输入

- `E3_main_32.json`：离线主测的 32 个题号及归档题面。
- `E3_online_4.json`：在线辅助的 4 道题，分别为 E3-A04、E3-F02、E3-F04、E3-G04。
- `E3_diagnostic_1.json`：独立补充诊断题 E3-F06，不计入 192 份离线主测回答或 24 份在线辅助回答。
- `E3_fixed_inputs.json`：离线题目所引用的固定数据对象，以 `fixture` 字段连接题目。

题面来源于归档的 `evals/semantics/items.yaml`，题目分组依据 E3 逐回答计数表中的题号和 tier。固定输入来源于同目录的 `fixtures_real.yaml`，文件中只保留数据字段。附录 B.5 列出题面与答案键要点，B.6 列出评分判据；任务输入与答案键应按实验配置分别提供。

离线主测为 32 题 × 2 配置 × 3 次重复＝192 份回答，在线辅助为 4 题 × 2 配置 × 3 次＝24 份回答。补充诊断题单列，不能加入主测分母。
