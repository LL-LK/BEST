## 二、给用户的回答

**BEST 给不了影像，这是能力边界，不是我漏了参数。** BEST 是**测光星表服务**：它提供的是每个源的位置、星等、误差、质量标记这些**表格记录**，没有像素数据。我这 7 个工具（名称解算 / 星表清单 / 列元数据 / 锥搜 / 批量匹配 / 计数 / 翻页）全部返回 JSON/CSV 形态的记录，没有任何一个能产出图片。所以"巡天影像"这件事必须去图像归档那边取。

**好消息是你要的图可以直接打开看，链接我给你：**

**Pan-STARRS（ps1，g/r/i 合成彩色）—— 这个最对口，因为 BEST 的 ps1 就是它的星表：**
```
https://ps1images.stsci.edu/cgi-bin/ps1cutouts?pos=180.0+30.0&filter=color&filter=g&filter=r&filter=i&filetypes=stack&auxiliary=data&size=480&output_size=0&verbose=0&autoscale=99.500000&catlist=
```
打开就是 RA=180.0、Dec=30.0 处的彩色堆叠图，480 像素视场；页面上还能切换单波段、调视场大小、叠加星表标注。

**SDSS（同一个天区，也在这个位置有覆盖）：**
```
https://skyserver.sdss.org/dr18/SkyServerWS/ImgCutout/getjpeg?ra=180.0&dec=30.0&scale=0.4&width=512&height=512
```
直接返回 JPEG，`scale=0.4` 是角秒/像素，512×512 约 3.4 角分见方。

**Legacy Survey（DESI 影像，覆盖更深的北天）：**
```
https://www.legacysurvey.org/viewer?ra=180.0&dec=30.0&layer=ls-dr10&zoom=14
```
这个是交互式查看器，能缩放、切波段、叠加目录。

**我能替你做的部分**：图给不了，但"图里有什么"能给。用同一个坐标做锥搜，我可以把这个视场里的源列出来——位置、g/r/i/z/y 五波段 PSF 星等、`class_star`（点源还是星系），你拿着这份清单对着上面那张图看，比单纯看图信息量大得多。

要不要我按 **60 角秒**（约 1 角分，和上面那张 PS1 彩图视场接近）把这个场里的源查出来？或者你要更大的视场（比如 5 角分），说一声我放大半径——工具上限是 18000 角秒（5 度）。
