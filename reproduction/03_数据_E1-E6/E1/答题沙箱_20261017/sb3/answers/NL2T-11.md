## 二、给用户的回答

已按 RA=120.3°、Dec=−20.4°、半径 **5 角秒**查 `landolt`（Landolt 标准星表）。5″ 对标准星是正确的量级——标准星是点源、位置精度远好于 1″，5″ 既不会漏也不会并源；不要用 5′/1° 这种天区尺度，那只会把邻近星一起框进来。

**先说清"标准星"在 BEST 里指哪张表**（这一步最容易踩错）：
- `std` 是**导航分组，不是表**，直接查会拿到 Internal Server Error；它展开为 `scr_galah` / `scr_lamost` / `xpsp` 三张成员表。
- 经典的 Landolt 标准星在 `landolt` 这张 calib 表里（UBVRI + Gaia BP/RP/G + 视宁度改正星等），是"按位置找标准星"的首选。我按这个理解打的 `landolt`。

**判读口径（重要）**：`landolt` 全表只有 45712 行摊到全天，约 **1 行 / 3.7 deg²**，所以任何 5″ 锥**大概率 0 行——这是正常结果，不是查询失败**。判据是 `getcount` 返回 0 且 HTTP 200 正常回包（不是软 404）。

如果 0 行，说明这个位置附近没有 Landolt 星。可选：
1. 放宽到 30″–60″（会引入邻近源，需按角距挑最近邻——我可以开 `nearest_only=true`）；
2. 改查 `scr_galah` / `scr_lamost` / `xpsp`（基于 Gaia XP 的 SCR 标准星，覆盖更广但只含 4500–6500 K 矮星、Av<0.1 的子集）；
3. 你如果本来是想查某个具体标准星的**定标值**，把名字给我，我用 `resolve_name` 解算后按名字定位更靠谱。

另外提醒：本表 `umag` 一列的不确定度最差（官方口径 U 波段 <10 mmag，BVRI 1–2 mmag），做 U 波段定标时注意这一档差异。
