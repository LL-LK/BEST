## 二、给用户的回答

BEST 当前可查 **12 张星表**，按站点导航分三组：

**Well-Calibrated（calib，8 张）**
- `ps1` — Pan-STARRS All-Sky（全天，g/r/i/z/y）
- `stripe82` — Well-Calibrated Stripe82（赤道精测天区）
- `gaia_dr3_18` — Well-Calibrated Gaia DR3（注意线上 id 带 `_18`，没有 `gaia_dr3` 这张表，旧拼写只作别名归一）
- `jplus_dr3` — Well-Calibrated J-PLUS DR3
- `smss_dr4` — Well-Calibrated SMSS DR4
- `landolt` — Well-Calibrated Landolt（经典标准星）
- `uss_dr1` — Well-Calibrated USS DR1
- `splus_dr4` — Well-Calibrated S-PLUS DR4

**Standard Stars（std，3 张）**
- `scr_galah` — 标准星 × GALAH 交叉表（137 列）
- `scr_lamost` — 标准星 × LAMOST 交叉表（137 列）
- `xpsp` — Gaia DR3 XP&SP 光谱-测光（139 张表单表，287 个可选列）

**other（1 张）**
- `dr3xpcorr` — 修正后的 Gaia DR3 XP 光谱（17 列）

两个要避开的坑：
1. `std` / `calib` / `other` 是**导航分组，不是表**。拿组名当星表 id 查会得到软错误（组名自身返回 Internal Server Error，带组前缀的路径返回 Not Found），必须用上面 12 个裸 id。
2. 官网文档页列了 SkyMapper DR4，但线上不可查询（`/skymapper_dr4/f` 软 404），**文档存在 ≠ 可查询**。

另外提醒口径：能查 ≠ 该天区有数据。`stripe82` 只覆盖赤道精测天区，`smss_dr4`/`splus_dr4` 只覆盖南天巡天天区，锥区落在天区外返回 0 行是正常结果。
