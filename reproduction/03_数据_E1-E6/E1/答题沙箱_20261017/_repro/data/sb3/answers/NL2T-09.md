## 二、给用户的回答

先按名字解算（BEST 里"按名字查星"只有这一个入口，没有名字索引表），再用解出来的坐标去标准星表做锥搜。

**一个必须先说清的语义**：`std` 是导航分组，**不是可查询表**——直接查 `std` 会拿到 Internal Server Error。标准星实际落在这几张表里：

- `landolt` — Landolt 标准星（UBVRI + Gaia 测光，含改正星等）。**你要的"标准星记录"首选这张。**
- `scr_galah` / `scr_lamost` — 标准星 × GALAH / LAMOST 交叉表（137 列，含各巡天交叉测光）。
- `xpsp` — Gaia DR3 XP&SP 光谱-测光（287 列）。

所以我先打 `landolt`，半径 60″（3 角分内没有第二颗 Landolt 星的可能性很高，60″ 足够把参宿四自己框住）。

**预期与判读**：
- `landolt` 全表只有 45712 行摊到全天，约 **1 行 / 3.7 deg²**，任何 0.5° 锥大概率 0 行。60″ 锥命中就命中，**返回 0 行是正常结果，不是故障**，我不会把它当错误报给你。
- 如果 `landolt` 0 行，我接着打 `scr_galah` / `scr_lamost` / `xpsp`（同样是 60″ 锥）。这三张是"基于 Gaia XP 的 SCR 标准星"，覆盖的是 4500–6500 K 矮星、Av<0.1 的子集——**参宿四是红超巨星（M1-2 Ia-ab），大概率不在这套子集里**，0 行同样正常。
- 参宿四是变星（V 约 0.0–1.6 等不规则变化），Landolt 表里给的是定标时刻的星等，不是"当前亮度"。要光变请走时序巡天，BEST 不提供逐历元数据。
