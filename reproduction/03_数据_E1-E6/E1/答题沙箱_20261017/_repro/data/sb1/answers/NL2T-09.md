# NL2T-09

## 一、调用轨迹

1. resolve_name  参数: {"name": "Betelgeuse"}
2. cone_search  参数: {"ra": 88.79, "dec": 7.41, "radius_arcsec": 60, "catalog": "scr_lamost", "nearest_only": true}

## 二、给用户的回答

按名字走：先用 `resolve_name` 把 Betelgeuse 解成 ICRS 坐标（约 **RA 88.79°、Dec +7.41°**，以工具回包为准），再拿这个坐标去标准星表做锥搜。

但这里有个**结构性预期，得先跟你说清楚，免得你看到 0 行以为查错了**：

1. **"标准星"不是一张表。** BEST 的 `std` 是导航分组，成员是 `scr_galah`、`scr_lamost`、`xpsp` 三张，组名本身不能当星表 id 查（会回 Internal Server Error）。我默认用了 `scr_lamost`；要 GALAH 交叉或 Gaia XP 光谱就换 `scr_galah` / `xpsp`。
2. **Betelgeuse 大概率不在 SCR 标准星集里。** SCR 标准星的入选口径是 **4500–6500 K 的矮星、且消光 Av < 0.1 mag**；Betelgeuse 是 M1–M2 Ia 红超巨星，有效温度约 3600 K，从一开始就不在筛选范围内。所以"标准星记录"这一问，正确答案很可能是"没有这条记录"，而不是"有但没查到"。
3. **半径口径**：`scr_lamost` / `scr_galah` 极稀疏，实测 300″ 锥就回 0 行、1800″ 才有 1–137 行。我这里用 60″ + `nearest_only`，是为了"按名字定位这颗星"；如果目的是"这片天区有哪些标准星"，半径要放大到 1800″ 量级才有意义。

如果你要的其实是这颗星**在 BEST 里的测光**（不是"标准星身份"），那是另一条路：同一坐标查 `gaia_dr3_18`（G/BP/RP）和 `ps1`（g/r/i/z/y），这两个表覆盖全天、不挑矮星。说一声我直接换表查。
