# NL2T-18

## 一、调用轨迹

无（本题不调用任何工具，理由见下）

## 二、给用户的回答

**"那个源"我定位不到，缺的是「天体标识」这一维——你没指明是哪个源。** 我们之间没有上文，也没有名字、没有坐标、没有编号，任何一个具体对象都指不出来。我手上这 7 个工具全部以"一个明确的天体标识或位置"为输入，没有"猜一个"的余地——猜错比不查更糟。

请用下面任意一种方式告诉我，任一条都能让我立刻开工：

1. **天体名** —— 一个星系、星团或亮星的名字即可。我用 `resolve_name` 解算成 ICRS 坐标再查。
2. **坐标 + 半径** —— 给出中心赤经赤纬（十进制度）和一个搜索半径（**单位是角秒，不是度**）。这条最直接，一步到位。
3. **星表内的编号** —— 某张星表的 source id。但要注意：**本工具面不能按编号直接检索**，只能按位置锥搜。所以给我编号的同时，得给我它的坐标，或者告诉我该编号来自哪张表、你想查什么。
4. **之前的查询会话** —— 如果你指的是某次已经查出来的结果里的某一行，把会话 id 或者那一行的 source id 给我，我按会话翻页定位。

另外请顺带说一下**要查它的什么**，这决定我调哪个工具：

- 要**坐标** → 名称解算（`resolve_name`）
- 要**这个位置有哪些源 / 测光值** → 锥形检索（`cone_search`），顺便说清要哪张星表：BEST 提供 Pan-STARRS 五波段、Gaia DR3 定标子集、S-PLUS 南天 12 波段等
- 要**一批坐标批量匹配** → 批量交叉匹配（`crossmatch_batch`）
- 只要**数量** → 计数（`count`）

给我一句话，我就发。
