# NL2T-14

## 一、调用轨迹

1. `cone_search`  参数: {"ra": 187.5, "dec": 20.0, "radius_arcsec": 60, "catalog": "ps1", "columns": ["ps1_ra", "ps1_dec", "ps1_gpsf", "ps1_rpsf", "ps1_ipsf", "ps1_zpsf", "ps1_ypsf", "ps1_class_star"], "max_rows": 1000}

## 二、给用户的回答

**先把坐标换算成工具要的十进制度**（工具只收度，不收时角/度分秒）：

- RA = 12h 30m 00s → **187.5°**（12h × 15 = 180°，30m × 15/60 = 7.5°）
- Dec = +20° 00′ 00″ → **+20.0°**

**半径是我替你定的，说明一下理由**：你说"附近"，没给尺度。我取 **60 角秒（1 角分）** 起步——这是"看看这个点周围有什么"的常规口径，够覆盖一个点源附近的邻近源，又不至于把整片天区都拖进来。这个锥在 ps1 里大约是百行量级（同纬度天区 60″ 锥的留档实测 174 行），一次就能取全。

查的是 `ps1`（Pan-STARRS 全天，g/r/i/z/y 五波段 PSF 星等），列裁到坐标 + 五波段星等 + 点源分类。

**读结果时注意两件事**：

1. 这个天区在 SDSS/ps1 的连续覆盖区里，源密度正常，不会是 0 行。但**大部分源在某个波段没有测光**——`ps1_gpsf` 之类会返回 `nan` 或落在 ≈ −1004 的哨兵带上，`*_psf_err` 是 `-999.0`。按星等筛之前要先把哨兵剔掉，否则"没测光"会被当成"很暗"。
2. 星等是 **PSF 星等**，不是孔径星等。要跟别的星表做颜色，注意口径一致。

**半径要不要改，你定**：

- 想看某个具体源的邻域 → 3–10 角秒足够；
- 想看这个位置的一小片天区（比如几角分见方的场）→ 60–300 角秒；
- 想看一个星系/星团的整体 → 那得先告诉我是哪个天体，按它的角径给半径（工具上限 18000 角秒 = 5 度）。

另外，如果你其实是想问"这个坐标上是什么天体"，那是名称反查，`resolve_name` 只能"名字 → 坐标"、做不了"坐标 → 名字"；这种需求得靠外部星表（SIMBAD/NED）按位置查，本工具面不提供。告诉我你要哪种，我接着做。
