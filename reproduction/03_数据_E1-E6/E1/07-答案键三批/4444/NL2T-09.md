# NL2T-09
## 用户原话
> 按名字查这颗星在 BEST 的标准星记录。
## 判定
先澄清再调用 —— 「按名字」这一诉求本身在能力边界内（`resolve_name` 是「按名字查星」的唯一入口），但本句**缺天体名**（「这颗星」无指代、无前文），且「标准星」存在 std 导航组与 Landolt 定标星表两解；名字与范围补齐前不得发请求，补齐后走 `resolve_name` → `cone_search`。
## 期望调用
```python
from src.ai_tools import ToolBox

# 当前先澄清: 名字/范围未定, 此刻不发任何调用 (不编造天体名与坐标)。

box = ToolBox()

# 第 1 步: 按名字解算 (resolve_name 是智能体「按名字查星」的唯一入口)
r = box.resolve_name(name)                      # name 待用户给出, 如 "M31"/"HD 12345"
if not r.status["ok"]:                          # 失败一律先看稳定码, 不嗅探消息文本
    # E_NAME_UNRESOLVED (Sesame 查无此名) / E_INVALID_INPUT (空串等) / E_BACKEND
    raise SystemExit(r.status["error_code"])
ra, dec = r.data["ra"], r.data["dec"]           # 单位: 度 (ICRS), 与 cone_search 同口径, 无需换算

# 第 2 步: 以该坐标在 Standard Stars 组上锥搜 (std 组由客户端展开为三张成员表并合并)
rec = box.cone_search(
    ra=ra, dec=dec,                             # 度 (ICRS)
    radius_arcsec=180.0,                        # 角秒; 工具缺省 180″=3′ (上限 18000″=5°)
    catalog="std",                              # 导航组: 展开 scr_galah/scr_lamost/xpsp, 不得只查单表
    nearest_only=True,                          # 单星取最近邻
    max_rows=1000,                              # 行数预算, 超出则 status.truncated=true 再 fetch_page
)
```
## 参数与换算
- `name`（`resolve_name`）：取用户给出的天体名（Sesame 可解析形式）。本句「这颗星」无指代 → **待澄清，不编造**；不得凭空填 "M31" 之类。
- `ra` / `dec`（`cone_search`）：由 `resolve_name` 回包的 `data["ra"]` / `data["dec"]` 直取，**单位均为度（ICRS）**，与 `cone_search` 的入参口径一致，无需换算；值域由 `guards.validate_coordinate` 强制（ra∈[0,360)，dec∈[-90,90]）。
- `radius_arcsec`：**单位是角秒（arcsec），不是度**。缺省 180.0（=3′=0.05°）。换算：1°=3600″，1′=60″；若用户给「3 角分」→3×60=180″，给「5 角秒」→5.0。上限 18000″（=5°），由 `guards.validate_search_radius` 强制，越界 → `E_INVALID_INPUT`。
- `catalog="std"`：`std` 是 Standard Stars 导航组（成员 scr_galah / scr_lamost / xpsp）；`cone_search` 侧会展开为全部成员并合并（按成员数分摊 max_rows）。若用户只要某一张成员表，则改传裸 id（如 `"scr_lamost"`）。
- `nearest_only=True`：单颗星取最近邻（可选，缺省 False）。
- `max_rows=1000`：`cone_search` 工具缺省值；截断时 `status.truncated=true`，再用 `fetch_page(sqlid, page, page_size)` 续取（`page_size`≤10000）。
- 零请求前置（可选、不替代上面的调用）：`list_catalogs()` 可离线确认「标准星 → std 组 → scr_galah/scr_lamost/xpsp」；`describe_catalog("scr_lamost")` 等可离线取列清单与单位说明。

## 陷阱与错法
1. **把名字直接塞给 `cone_search`**：它没有 name 参数，且 ra/dec 必填 → 直接 `E_INVALID_INPUT`。按名字必须先 `resolve_name`。
2. **凭空编天体名或坐标**：本句无指代，编出来就是假记录，违反「缺参数不编造」；`cone_search` 也明确不把缺坐标当 (0,0)。
3. **`catalog="std"` 到处乱传**：`describe_catalog("std")` 会被 `resolve_catalog` 拒（enum 无 std）→ `E_INVALID_INPUT`；但 `cone_search(catalog="std")` 合法（组展开）。反之若直接拿 std 当表名去 `/q` 路由，会拿到 HTTP 200 + `{"error":...}` 的软 404（状态码门控看不见）。
4. **半径单位搞错**：`radius_arcsec` 是角秒。误当度传 0.05 → 0.05″ 近空锥；误传 180 当度 → 180° 超 18000″ 上限被拒。
5. **绕过工具面**：直接调 `BestClient.query_standard_stars()` 不是 agent 工具面（唯一对外面是 `ToolBox` 的 7 个工具，P1-9）；且它默认 `table="scr_lamost"` 只查一张表，会让人误以为查了标准星全集。
6. **用零请求工具冒充结果**：`list_catalogs` / `describe_catalog` 只给星表清单与列元数据，不含任何记录，不能当「标准星记录」作答（只可作成员确认的前置步骤）。
7. **「标准星」歧义**：`std` 组是 Standard Stars；Landolt（`landolt`，calib 组，显示名 Well-Calibrated Landolt）也是「标准星表」，但属另一组，不能混用。
8. **不判 `status.ok` 就取 `data["ra"]`**：失败信封 `data` 只有 `{"error": ...}`，硬取会 KeyError；Sesame 的 `ra=dec=-1000` 哨兵已在协议层拦成 `E_NAME_UNRESOLVED`，但仍须先看稳定码。
9. **把未接线的门禁当已判**：`http_status`/`checksum_match` 当前生产链路无填充点（SKILL.md Q-08），不得声称已判过。
## 若需澄清，问什么
必答：
- **这颗星的名字是什么？** 请给 Sesame 可解析的形式（如 `M31` / `HD 12345` / `Vega`）。「按名字查」在本 skill 里由 `resolve_name` 把名字解成 ICRS 坐标后锥搜；本句「这颗星」没有指代对象，无法直接调用。

选答（可给默认）：
- **「标准星」指哪一套？**（A）BEST Standard Stars 导航组 `std`（成员 scr_galah / scr_lamost / xpsp，默认全组展开）｜（B）只要其中一张成员表（请点名）｜（C）Landolt 定标星表（calib 组，属「标准星」的另一含义）。
- **检索半径与是否只取最近邻？** 默认 180″=3′、取最近邻；若要严格单源匹配可给 3–5″。
