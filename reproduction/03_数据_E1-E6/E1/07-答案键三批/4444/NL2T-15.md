# NL2T-15
## 用户原话
> 在 RA=180.0、Dec=30.0、半径 60″ 内查 Gaia DR3 的 G 星等。
## 判定
直接调用 —— 单锥心 + 半径的锥形检索，四要素（坐标/半径/星表/波段）齐全无歧义，直接调 `cone_search`（catalog 取规范 id `gaia_dr3_18`，columns 取 G 波段列 `gaia_dr3_18_phot_g_mean_mag`）。
## 期望调用
```python
from src.ai_tools import ToolBox

box = ToolBox()
result = box.cone_search(
    ra=180.0,                                 # 度, ICRS（用户已给度数）
    dec=30.0,                                 # 度, ICRS（用户已给度数）
    radius_arcsec=60.0,                       # 60″ 本就是角秒，直接传 60.0，无需换算
    catalog="gaia_dr3_18",                    # 注册表规范 id；旧拼写 "gaia_dr3" 会经 CATALOG_ALIASES 归一到它
    columns=["gaia_dr3_18_phot_g_mean_mag"],  # G 波段星等列（CATALOG_MAG_COLUMNS 中 band 标签 "g"）
)
# 其余参数走缺省：sort=None、order="asc"、nearest_only=False、max_rows=1000
```
## 参数与换算
- **ra=180.0**：用户给的即度数，落在 `[0, 360)` 合法区间（`validate_coordinate` 与 `build_query_form` 均按度校验）。
- **dec=30.0**：已给度数，落在 `[-90, 90]` 合法区间。
- **radius_arcsec=60.0**：用户说“半径 60″”，″ 即角秒（arcsec），与 skill 的口径**同单位，直接照抄、不换算**。60 满足 `(0, 18000]`（`validate_search_radius` 上限 18000″=5°）。若误当“度”直接传 60 或误乘 3600 传 216000，都会得到完全不同的天区或被上限拒绝。
- **catalog="gaia_dr3_18"**：BEST 12 张可查表的规范 id（`CATALOG_PATHS` 的键，查询路由 `gaia_dr3_18/q`，显示名 “Well-Calibrated Gaia DR3”）。用户说的 “Gaia DR3” 即此表。旧拼写 `gaia_dr3` 由 `CATALOG_ALIASES={"gaia_dr3": "gaia_dr3_18"}` 归一，两种写法都能过 `resolve_catalog`，但**准确 id 是 `gaia_dr3_18`**（漏写 `_18` 正是本题主陷阱）。
- **columns=["gaia_dr3_18_phot_g_mean_mag"]**：“G 星等”= Gaia G 波段平均星等。`CATALOG_MAG_COLUMNS["gaia_dr3_18"]` 把波段标签 `"g"` 映射到裸列名 `phot_g_mean_mag`；该列在 `CATALOG_COLUMNS["gaia_dr3_18"]` 中以带前缀形式发布，故取全名 `gaia_dr3_18_phot_g_mean_mag`。`cone_search` 的 `columns` 即 `showcol`，经 `qualify_column` 白名单校验（接受带前缀 / 裸名 / `表.列` 三种拼写）。
- **缺省项**：`max_rows=1000`（超出 `truncated=True`，可用 `fetch_page` 续取）、`nearest_only=False`、`order="asc"`、`sort=None`（协议层按表自动注入定序键 `gaia_dr3_18_source_id`）。用户未提限行/最近邻/排序，保持缺省即可，不臆造。

## 陷阱与错法
1. **表名漏 `_18`**：只写 `"gaia_dr3"` 时 `resolve_catalog` 能靠别名兜住，但直接拿它当唯一键去查 `CATALOG_PATHS` / `CATALOG_COLUMNS` / `CATALOG_MAG_COLUMNS` 会查不到（这三张表都没有 `gaia_dr3` 键）。规范写法是 `gaia_dr3_18`。
2. **把 “G 星等” 当成 G_RVS**：`CATALOG_MAG_COLUMNS` 里 `grvs_mag → "grvs"` 是分光 G_RVS 星等，与测光 G 不是一个量；G 波段的标签是 `"g"`。
3. **误取 `phot_g_mean_mag_y21`**：`CATALOG_COLUMNS` 里确有 `gaia_dr3_18_phot_g_mean_mag_y21`（Y21 改正列），它与 `phot_g_mean_mag` 数值极接近，但不在波段映射表里，不是标准 G 星等列。
4. **误取流量列**：`phot_g_mean_flux` / `_flux_error` / `_flux_over_error` 是流量不是星等，`CATALOG_MAG_COLUMNS` 故意不收。
5. **半径单位**：把 60″ 当 60 度（实际搜 60°）或乘 3600 成 216000″（超 18000″ 上限）——一个搜错天区、一个被入口拒，都错。
6. **columns 传波段标签 `"g"` 而非列名**：`qualify_column` 会把 `"g"` 当裸列名去该表列集合里找，`gaia_dr3_18` 没有名为 `g` 的列 → `E_INVALID_INPUT`。必须传列名（裸名 `phot_g_mean_mag` 或带前缀 `gaia_dr3_18_phot_g_mean_mag`）。
7. **误用 `crossmatch_batch`**：那是“一批坐标一次性匹配”的工具；本题只有单个锥心 + 半径，应走 `cone_search` 的原生 `pos.type=cone`。
8. **误称可走 TAP/ADQL**：BEST 无 TAP/ADQL 端点，`validate_adql_query` 只做形状校验，不能当查询通道。

## 若需澄清，问什么
无需澄清。坐标、半径、星表、波段四要素齐全且无歧义——“Gaia DR3” 在 BEST 注册表里唯一对应 Well-Calibrated Gaia DR3（`gaia_dr3_18`），“G 星等”唯一对应 `phot_g_mean_mag`。
