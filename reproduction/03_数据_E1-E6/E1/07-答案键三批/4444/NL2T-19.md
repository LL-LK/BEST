# NL2T-19

## 用户原话
> 给我一份标准星清单。

## 判定
先澄清再调用 —— BEST 无「无条件导出整张表/整份清单」能力（7 个原子工具里凡返回星行的都必须带天区约束），且「标准星」在注册表里跨 3~4 张表（std 组三成员 + 经典标准星表 landolt），天区与表选择两项关键参数都缺，必须先问清再发请求。

## 参数与换算
- **ra / dec（度, ICRS）**：无任何无约束取数路径，`cone_search` 的 schema `required: ["ra","dec"]`；取值由 `guards.validate_coordinate` 判 `ra∈[0,360)`、`dec∈[-90,90]`。用户未给 → 必须澄清（**绝不填 0/0**）。
- **radius_arcsec（角秒）**：`guards.validate_search_radius` 判 `0 < r ≤ 18000`。换算：`18000″ = 5°`；`180″ = 3′`（工具缺省值）。若用户口述「0.5 度」→ `0.5×3600 = 1800″`；口述「3 角分」→ `3×60 = 180″`。**单位口径是角秒，传度会得到 0 行或 360 倍半径**。
- **catalog（裸 id）**：候选 `scr_galah` / `scr_lamost` / `xpsp`（`CATALOG_GROUPS["std"]` 三成员）与 `landolt`（`CATALOG_DISPLAY["landolt"]="Well-Calibrated Landolt"`，经典标准星表，属 calib 组）。**组名 `"std"` 不是表，禁止传**（`/std/q` 软 404）。用户未指明 → 必须澄清。
- **columns（showcol 投影）**：先 `describe_catalog(catalog)` 取该表登记列（零请求），再投影；不传 = 全列（大星表费带宽）。
- **max_rows（行预算，默认 1000）**：工具层封顶，超出置 `truncated=True`，由 `fetch_page(sqlid, page, page_size≤MAX_FETCH_PAGE_SIZE=10000)` 续取；`count(sqlid)` 可在拉数前读服务端真实总数。**这是「一份清单」的合法落地方式：分页拉取，而不是无约束导全表。**
- **星等亮端**：片段口径 `<13 mag 需确认需求`（饱和），故若用户要亮星清单，需在澄清中一并确认星等范围/波段。

## 陷阱与错法
1. **拿 `list_catalogs` 当答案**：它零请求、但它回的是「12 张星表清单」，不是「标准星清单」。用户要的是天体，答成表清单 = 答非所问。
2. **`catalog="std"`**：组名不是表，`/std/q` 返回 HTTP 200 + 软错误体 → `E_SOFT_404`；`http_status==200` 门禁看不见它。必须展开成成员裸 id。
3. **以为能无约束导全表**：`query_standard_stars(constraints=[])` 在 client 面确实能建空约束表单，但那违反 best_catalogs.md「严禁全量拉取」（数百 MB 级），且该方法不在 agent 7 工具内；agent 侧不存在任何「整表导出」入口。
4. **编造 ra/dec（如 0,0）**：会静默查到赤道原点；各表天区互不重叠，换天区就换覆盖，结果会呈现「天上没源」的假象。
5. **半径单位错**：传「度」当角秒 → 0 行或 360× 半径；反之亦然。缺省 180″=3′ 而非 3°。
6. **表选择漏项**：只想到 scr_* 三张、漏掉 `landolt`（经典标准星表）；或反把 `landolt` 当 std 组成员（它在 calib 组）。
7. **忘了亮端饱和**：`<13 mag` 需确认需求，不能默认给「最亮的一批」。

## 若需澄清，问什么
1. **要哪张（哪些）标准星表？**
   - A. `scr_galah`（Standard Stars / SCR GALAH）
   - B. `scr_lamost`（Standard Stars / SCR LAMOST）
   - C. `xpsp`（Standard Stars / Gaia DR3 XP&SP）
   - D. `landolt`（Well-Calibrated Landolt，经典标准星表）
   - E. std 组全部三张（分别锥搜后合并）
   （注意：`std` 是导航分组、不是可查询表，只能按成员取。）
2. **要哪个天区？** 因为没有任何无条件全表导出能力，必须给：中心 RA、Dec（度）+ 半径（角秒；如 1800″ = 0.5°）。或改为提供一批已知标准星坐标（走 `crossmatch_batch`）。
3. **星等范围 / 波段？** 亮端 `<13 mag` 会饱和，请给极限星等与所需波段（如 g/r/i/z），否则默认全列。
4. **要哪些列、什么格式？** 默认该表全列 CSV；可先 `describe_catalog` 列出候选列再裁剪。
