# NL2T-08

## 题面

> 结果被截断了，继续取下一页。

## 判定

- 类别：**直接调用**（`call`）
- 目标工具：`fetch_page`

## 期望调用

```python
fetch_page(sqlid="<上一轮 provenance.session_id>", page=2, page_size=1000)
```

## 关键要点 / 坑位

- 截断后凭 sqlid 续页, 不重新 POST 表单——重建会话既多一次往返, 也可能拿到不同的结果集。
- 页号从 1 起, page_size ∈ [1, 10000](越界 ValueError→E_INVALID_INPUT); max_rows 缺省取 page_size, 要跨页累积须显式传更大值。
- 红线反模式: 重新 cone_search 一遍并加大 max_rows(重新提交表单, 不是续页); 或把上一页当全部数据直接用。

## 给用户的回答口径

调用 fetch_page(sqlid, page=2, page_size=1000), 并用 returned_count/total_count 判断还有没有下一页, 逐页续到取完。
