# NL2T-02

## 题面

> ps1 表有哪些列和波段？

## 判定

- 类别：**直接调用**（`call`）
- 目标工具：`describe_catalog`

## 期望调用

```python
describe_catalog(catalog="ps1")
```

## 关键要点 / 坑位

- 列清单与波段映射是编译期注册表, describe_catalog 零请求就地作答, 不必也不能去'查一行数据看列名'。
- catalog 必须传裸 id 'ps1'; 带分组前缀(如 'calib/ps1')会被协议层拒(E_INVALID_INPUT)。
- data.units_note 已声明 ra/dec=度、星等=mag、半径=角秒, 单位直接引用信封, 不另猜。

## 给用户的回答口径

调用 describe_catalog('ps1'), 用返回的 data.columns 与 data.magnitude_bands(gpsf/rpsf/ipsf/zpsf/ypsf → g/r/i/z/y)作答; 说明误差列与 flags 位掩码含义须查列元数据页, 未核实前不解释各位含义。
