# NL2T-14

## 题面

> 坐标 12h30m00s +20°00′00″ 附近有什么？

## 判定

- 类别：**直接调用**（`call`）
- 目标工具：`cone_search`

## 期望调用

```python
cone_search(ra=187.5, dec=20.0, radius_arcsec=180.0, catalog="ps1")
```

## 关键要点 / 坑位

- Sexagesimal → 度: 12h30m00s = 12.5 h × 15 = 187.5°; +20°00′00″ = +20.0°; 不换算直接把 '12h30m00s' 传给 ra 是错的(ra 只收浮点度)。
- '附近'没给半径 → 用工具默认 180″ 并显式声明假设, 或先问用户要半径。
- 未指定表时按默认 ps1, 同样要显式声明。

## 给用户的回答口径

换算成 (187.5, 20.0) 度后锥搜, 声明默认半径 180″ 与默认表 ps1, 结果带 total_count。
