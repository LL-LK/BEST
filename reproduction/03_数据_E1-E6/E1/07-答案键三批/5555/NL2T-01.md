# NL2T-01

## 题面

> BEST 能查哪些星表？

## 判定

- 类别：**直接调用**（`call`）
- 目标工具：`list_catalogs`

## 期望调用

```python
list_catalogs()
```

## 关键要点 / 坑位

- 问的是'能查哪些表' = 注册表清单, 走零请求的 list_catalogs, 不发任何线网请求。
- 不得凭记忆背表名/张数——清单以 data.catalogs 现场组装结果为准。
- 分组页 std / calib 是导航分组、不是可查询表(/std/q、/calib/{id}/q 都回内部错误), 回答时不要把组名当表给用户。

## 给用户的回答口径

调用 list_catalogs 取当前可查询星表清单(cost.http_requests=0)。返回后再按 id 逐条说明; 若用户接着问某张表的列与波段, 再走 describe_catalog。
