# NL2T-21

## 题面

> RA=180.0、Dec=30.0、半径 60″ 内，这个天区最亮的源是哪颗？按 r 波段排。

## 判定

- 类别：**直接调用**（`call`）
- 目标工具：`cone_search`

## 期望调用

```python
cone_search(ra=180.0, dec=30.0, radius_arcsec=60.0, catalog="ps1", columns=['ps1_ra', 'ps1_dec', 'ps1_rpsf', 'ps1_rpsf_err'], sort="ps1_rpsf", order="asc")
```

## 关键要点 / 坑位

- '按 r 波段排'用 sort=ps1_rpsf + order=asc(星等越小越亮), 不是 nearest_only——nearest_only 只给最近邻, 与亮度无关。
- 哨兵陷阱: ps1 无测光行的值是 -1004.* 一族哨兵(比任何真实星等都小), 服务端按列排序时哨兵照样参与, 直接取第一行会拿到'没测光'的源; 必须取回后按 value <= -999.0 剔除哨兵再取最亮。
- 用有值的那一列: ps1_rpsf 有值, ps1_rpsf_corr 整列为空(空列不是另一个口径的星等); 报数必须带列名。

## 给用户的回答口径

按 ps1_rpsf 升序取回, 本地剔除哨兵后给最亮源(带 ra/dec、星等与误差、列名), 并说明剔除了多少行哨兵。
