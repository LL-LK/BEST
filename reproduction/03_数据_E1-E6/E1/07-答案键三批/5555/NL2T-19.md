# NL2T-19

## 题面

> 给我一份标准星清单。

## 判定

- 类别：**先澄清再调用**（`clarify`）
- 目标工具：`list_catalogs`

## 期望调用

```python
list_catalogs()
```

## 需要澄清的点

- 不存在'导出标准星清单'的端点: std 是导航分组不是表(/std/q 回内部错误), 标准星的真实成员是 scr_galah / scr_lamost / xpsp 三张表。
- '清单'必须有范围: 哪一张表 + 哪个天区(坐标 + 半径); 全表导出无约束会把请求放大到数百 MB 量级。

## 关键要点 / 坑位

- 先用 list_catalogs 把三张标准星表摆出来, 再让用户选表 + 给天区, 然后 cone_search 出清单。
- 红线: 不得用 std 当表名; 不得无约束全量导出; 不得因为 landolt 恒 0 就把它说成'表没了'。

## 给用户的回答口径

先 list_catalogs 说明三张标准星表, 要用户选表与天区, 再按位置锥搜给清单(带 total_count 与截断说明)。
