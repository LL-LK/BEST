# NL2T-07

## 题面

> 查询 Gaia DR3 1234567890123456789 在 BEST 中的 ZTF g/r/i 星等。

## 判定

- 类别：**先澄清再调用**（`clarify`）
- 目标工具：`resolve_name`

## 期望调用

```python
resolve_name(name="Gaia DR3 1234567890123456789")
```

## 需要澄清的点

- BEST 没有按 source_id 查询的端点(/q 走位置锥搜或 proximity 批量坐标), 所以不能拿 id 直接查; 需要先把 id 变成坐标。
- ZTF g/r/i 列在标准星表(scr_galah 的 gztf/iztf/rztf、scr_lamost 同名三列), 要先确认取哪一张标准星表。

## 关键要点 / 坑位

- 第一步尝试 resolve_name('Gaia DR3 1234567890123456789') 走 Sesame 解析; 解析不到回 E_NAME_UNRESOLVED, 此时请用户提供坐标或转 astro-catalog 按 id 取坐标。
- 拿到坐标后 cone_search(catalog='scr_galah' 或 'scr_lamost', columns=[..._gztf/_iztf/_rztf])。
- 红线: 不得编一个 by-id 端点; 不得凭空给星等数值; 不得把 ZTF 星等说成 BEST 自己测的(测光经 BEST 重定标, 身份/天体测量来自 Gaia)。

## 给用户的回答口径

先说明 BEST 无 by-id 端点, 用 resolve_name 尝试解析该 Gaia 标识; 解析成功则按坐标锥搜标准星表取 ZTF g/r/i(带列名与误差), 失败则请用户提供坐标。
