# NL2T-09

## 题面

> 按名字查这颗星在 BEST 的标准星记录。

## 判定

- 类别：**先澄清再调用**（`clarify`）
- 目标工具：`resolve_name`

## 期望调用

```python
resolve_name(name="<待澄清的具体星名>")
```

## 需要澄清的点

- '这颗星'没有给出名字(题面无上下文), 需要具体名称。
- 标准星有三张真实成员表(scr_galah / scr_lamost / xpsp), 需要用户指定或由我说明差异后选择。

## 关键要点 / 坑位

- 链路是 resolve_name → cone_search(标准星表), 两段都不能跳: 名字不能直接当查询键。
- 标准星按位置找, 不按名字找(站点没有 by-name 端点); 解析出坐标后按位置锥搜。
- 红线: 不得用 'std' 当表名(std/calib 是导航分组, /std/q 与 /std/q 都回内部错误)。

## 给用户的回答口径

先要名字 → resolve_name 取坐标 → 在指定标准星表上 cone_search; 同时说明三张标准星表的口径差异与稀疏性。
