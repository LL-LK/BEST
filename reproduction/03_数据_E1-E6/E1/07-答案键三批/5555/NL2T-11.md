# NL2T-11

## 题面

> 查找 RA=120.3°、Dec=−20.4°、半径 5″ 内的标准星。

## 判定

- 类别：**先澄清再调用**（`clarify`）
- 目标工具：`cone_search`

## 期望调用

```python
cone_search(ra=120.3, dec=-20.4, radius_arcsec=5.0, catalog="scr_galah")
```

## 需要澄清的点

- 标准星有三张成员表(scr_galah / scr_lamost / xpsp), 未指定时先声明按哪一张查(此处按 scr_galah 并说明可调)。
- 5″ 极窄, 而标准星表实测很稀疏(scr_lamost 在 (180,30) 需 1800″ 才有 137 行、300″ 时 0; landolt 摊全天约 1 行/3.7 deg²), 0 命中是统计可解释的, 不是故障——先向用户说明, 再问要不要放宽半径。

## 关键要点 / 坑位

- 表名必须取三者之一的裸 id; 'std' 不是表, 传进去会拿内部错误。
- 0 行只证明'这张表 + 这个半径 + 这组约束下无记录', 不证明该位置没有标准星; 换半径/换表再判, 先换天区再判故障。
- 不得把 0 命中说成'表坏了'或'这颗星不存在'。

## 给用户的回答口径

在指定标准星表上按 5″ 锥搜, 并预先说明该半径下 0 命中属预期; 结果为空时给出放宽半径/换表的换查路径。
