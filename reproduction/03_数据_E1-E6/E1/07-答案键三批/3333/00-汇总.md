## 逐题判定一览

| 题号 | 用户原话 | 判定 | 关键动作 / 要点 |
|------|----------|------|----------------|
| 01 | BEST 能查哪些星表？ | 直接调用 | `list_catalogs()`（零请求）；须说明 `std`/`calib`/`other` 是导航组不是表 |
| 02 | ps1 表有哪些列和波段？ | 直接调用 | `describe_catalog(catalog="ps1")`（零请求，含列清单 + 波段映射 + 单位） |
| 03 | M31 的坐标是多少？ | 直接调用 | `resolve_name(name="M31")`；失败为 `E_NAME_UNRESOLVED`，哨兵 −1000 不得回灌 |
| 04 | RA=10.68、Dec=41.27、半径 60″ 内的 ps1 星 | 直接调用 | `cone_search(ra=10.68, dec=41.27, radius_arcsec=60, catalog="ps1")` |
| 05 | 1000 个坐标一次性匹配 | 直接调用 | `crossmatch_batch(coords=[...])` 一次提交（proximity），而非 N 次锥搜 |
| 06 | 先看这个天区有多少源，再决定拉不拉 | 需澄清 | 缺中心/星表；补齐后：`cone_search` 建会话 → `count(sqlid)` 看真实总数 → 再决定是否 `fetch_page` |
| 07 | Gaia DR3 id 在 BEST 的 ZTF g/r/i 星等 | 需澄清 | BEST 无按 `source_id` 直查端点，须先给坐标；ZTF 列只在 `scr_galah`/`scr_lamost` 交叉测光列（登记了 g/r），且只进 raw_data |
| 08 | 结果被截断，继续取下一页 | 直接调用 | `fetch_page(sqlid=上一轮 provenance.session_id, page=上页+1)`；不重建会话、不重发锥搜 |
| 09 | 按名字查这颗星的标准星记录 | 需澄清 | 缺名字；且"标准星"是导航组，须指定具体成员表（`scr_galah`/`scr_lamost`/`xpsp`，或 `landolt`/`uss_dr1`） |
| 10 | 刚才那片天区，半径 5 角分内有什么？ | 需澄清 | 换算 5′ = **300″**；缺中心坐标（本会话无历史），给"坐标 / 天体名走 resolve_name / 复述天区"三选项 |
| 11 | RA=120.3、Dec=−20.4、半径 5″ 内的标准星 | 需澄清 | 半径 5″ 已是角秒；必须先指定哪一张标准星表（不能查 `std` 组），`landolt` 级稀疏下小锥必 0 |
| 12 | 把范围扩大到半径 0.5 度 | 需澄清 | 换算 0.5° = **1800″**；缺中心坐标与星表 |
| 13 | 半径 6 度范围内都列出来 | 需澄清 | 6° = **21600″ > 18000″（5°）硬上限**，必被 `E_INVALID_INPUT` 拒；须收窄或多锥拼接，且缺中心/星表 |
| 14 | 12h30m00s +20°00′00″ 附近有什么？ | 直接调用 | 换算 **ra=187.5、dec=20.0**；`cone_search` 半径未给 → 用缺省 180″ 并声明 |
| 15 | 查 Gaia DR3 的 G 星等 | 直接调用 | `cone_search(catalog="gaia_dr3_18", radius_arcsec=60)`，投影 `gaia_dr3_18_phot_g_mean_mag`（G 波段登记名） |
| 16 | 要 S-PLUS 的 r 波段星等 | 直接调用 | `cone_search(catalog="splus_dr4")`，列 `splus_dr4_r_pstotal` + 误差 `splus_dr4_e_r_pstotal` |
| 17 | 筛选 r 波段误差 < 0.01 mag | 需澄清 | 工具面**无行过滤/列约束参数**，且缺天区；只能取回后本地筛，并先剔除哨兵与 `nan` |
| 18 | 帮我查一下那个源 | 需澄清 | 完全缺参数；按"名字 / 坐标 / 会话内上文"三路径追问 |
| 19 | 给我一份标准星清单 | 需澄清 | 7 个工具里没有"列标准星"端点；标准星只能按天区锥搜或按坐标批量匹配 |

| 21 | 这个天区最亮的源？按 r 波段排 | 直接调用 | `cone_search(catalog="ps1", sort="ps1_rpsf", order="asc")`；**升序头部是哨兵带**，须本地按 `<= −999.0` 剔除后再取最小 |

| 24 | 上传我的星表做交叉匹配 | 需澄清 | `crossmatch_batch` 收**坐标数组**不收文件上传；需用户给坐标清单（或先本地解析成 ra/dec 数组） |
