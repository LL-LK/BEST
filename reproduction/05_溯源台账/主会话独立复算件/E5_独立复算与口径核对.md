## 三、统计方法口径（必须与论文表述一致）

官方脚本 `evidence\confirmatory_stats.py` 的 `paired_exact_p` 是**基于 |Σ| 统计量的精确配对符号翻转**：对每题「成功数之差」的**幅度**做全符号翻转置换，零差保留同等任务权重。

> 注意：只用符号、丢弃幅度的符号检验（sign test）在本数据上得 p=1.0，是更弱的检验，**不可**替换官方口径。论文与台账应统一采用官方 |Σ| 口径。

## 六、需提请人工裁决的事项（台账标记，不自行改稿）

1. **主比较 B3−B2b 缺显著性表述。** 该比较是论文摘要的 headline（"规则通过率 56.55%，较原子工具基线高 7.14 个百分点"），复算精确 p=0.0885、任务聚类 bootstrap 95% CI 下界恰为 0.00。即：**数据库接入相对通用模型的贡献高度显著（p<1e-6），但"指导信息相对原子工具"的增量在 0.05 水平未达显著**。论文正文 `main.tex:482` 已就消融写过"增加指导信息不必然提升端到端表现"，但未对主比较本身给出显著性。是否补一句限定，属作者决定。
2. **B3−B2a 同样不显著**（p=0.1501），论文呈现 7.74 个百分点差值但未给 p。
3. **bootstrap 区间末位精度**。用 Python `random.Random` 复现 A5−B3 下界为 −8.33，用 numpy `default_rng(20261012)` 为 −8.93；区间本身一致，但**区间下界对 RNG 流敏感**，引用到小数点后两位属过度精确，建议引到整数个百分点。
4. **D07 可达性缺陷**属工具接口与题目严格条件的结构性不匹配（`cone_search` 未暴露 `page_size`，客户端默认 1000），不得计入模型能力。
