本目录是投稿包的**数字溯源中枢**：把论文里每一个报告数字，钉到可定位的证据文件、可重算的命令，以及一个明确的判定。

## 二、主表 schema（12 列，UTF-8 with BOM，Excel 可直开）

```
claim_id, 实验, 论文文件, 论文行号, 论文原文片段, 论文呈现值,
证据文件路径, 证据SHA256, 可复现命令, 一致性判定, 来源标签, 备注
```

- **一致性判定**只允许四值：`一致` / `不一致` / `口径不同` / `无证据`
- **来源标签**四选一：`[官方文档明文]` / `[官方产物文件]` / `[我方复现]` / `[原始归档]`

## 四、路径与占位符约定

包内统一使用占位符，替换是可逆的（映射表留在 `11_投稿包\_work\_复核\可逆映射_内部核对用.json`，**不随包外发**）：

| 占位符 | 含义 | 依据 |
|---|---|---|
| `<WORKSPACE>` | 原始工作区根目录 | 本轮清理 |
| `<HOME>` | 用户家目录 | 本轮清理 + 既有 R06/R07/R22 |
| `<USER_HOME>` | 用户家目录 | 既有 R06/R07/R22 |
| `<SANDBOX_HOME>` | 沙箱家目录 | 既有 R08 |
| `<REPO_ROOT>` / `<MONOREPO_ROOT>` / `<WORK_ROOT>` / `<TEMP_ROOT>` / `<TOOL_ROOT>` / `<SPILL_ID>` | 各类工作路径 | 既有 R09–R13、R21 |
| `HOST` / `HOST\user` / `user` / `user2` | 主机名与账号占位 | 既有 R04、R05、R20、R23 |
| `session-<SESSION_ID>` | 会话标识 | 既有 R14 |

**台账的「证据文件路径」列写的是原始归档中的相对路径**（相对工作区根），便于回原档核对；
本包内 `03_数据_E1-E6` 与 `04_复现源码` 是**官方脱敏最小复现包的展开副本**，文件哈希与原批次不同，
比对时以包内 `DESENSITIZATION-NOTICE.md` 与 `PACKAGE-MANIFEST.sha256.json` 为准。

## 五、怎么复算

台账「可复现命令」列给出可直接执行的命令。包内开箱可跑的三项：

```powershell
# E5 全量统计复算（2016 格 → 各臂通过率、精确配对符号翻转、Holm、bootstrap CI）
python 05_溯源台账\主会话独立复算件\verify_e5_independent.py
python 05_溯源台账\主会话独立复算件\verify_e5_contrasts.py

# E1 三箱加权分复算（旧链 vs 论文口径）
python 05_溯源台账\主会话独立复算件\verify_e1_batches.py
```

各证据线脚本（`各线复算脚本\`）依赖原工作区目录布局，在本包内不可直接运行，仅作审阅与改写参照。

## 六、判定口径的三个易混点

1. **E1 的两套口径不可混用** —— 旧链 0.9089/0.9089/0.9446（均值 0.9208）vs 论文 0.9429/0.9607/0.9554（均值 0.9530）。
   后者来自 2026-10-20「沿用原评分链重新判分」，证据在 `03_数据_E1-E6\E1\v55_重新判分_20261020\`。
2. **E5 的 p 值口径** —— 官方用**基于 |Σ| 统计量的精确配对符号翻转**（保留每题差值幅度）。
   若只用符号、丢弃幅度的符号检验，在同一数据上会得 p=1.0，是更弱的检验，**不可替换官方口径**。
3. **E3 的 UCR 口径** —— 论文取**三重复中位数**（30.2632%→30.26%）；池化口径为 207/691=29.96%，两者不可互换。
