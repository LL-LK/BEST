### 4.3 数值登记 / 主张登记

- 数值登记：`D` 数值原文、`E` 数值分类（可追溯/可推导/无来源/待核实）、`F` 依据来源定位、`G` 推导公式与限制、`H` 致命编数、`I` **逐项理由（≥8字）**、`J` 单位与计数口径、`K` 材料问题说明、`L` 补充证据；新增 `N` 评阅人ID、`O` 评阅日期、`P` 仲裁人ID、`Q` 仲裁记录ID。
- 主张登记：`D` 主张原文、`E` 主张分类（有支撑/无支撑/待核实）、`F` 依据来源定位、`G` **逐项理由（≥8字）**、`H` 材料问题说明、`I` 补充说明；新增 `K` 评阅人ID、`L` 评阅日期、`M` 仲裁人ID、`N` 仲裁记录ID。
- **每份材料各预留 3 行**。条目多于 3 条时：在表内插入行 → 复制同份的"顺序"与"匿名编号" → 填新的条目序号 → 复制该行状态公式。**不要追加到表格范围以外。**

### 4.4 仲裁记录

`仲裁记录ID | 匿名编号 | 争议表 | 争议条目ID或字段 | 评阅人A ID | A 取值 | 评阅人B ID | B 取值 | 分歧类型 | 仲裁人匿名ID | 仲裁日期 | 仲裁结论 | 仲裁理由（≥8字） | 最终采用值 | 是否影响主指标口径 | 备注`

**分歧触发条件（三选一即登记）**
1. 同一匿名编号、同一条目 ID 上两人判定不一致；
2. 一人填"待核实"、另一人给出结论；
3. 可用性分差 ≥ 2。

## 6. 标准作业流程

1. 主持人分配匿名 ID，发给评审 R1、R2（可再发 R3 作仲裁人），两份工作簿**各自独立**。
2. 每位评审先在 `01_评阅人登记` 填自己那一行。
3. 在 `审核总表` 按顺序逐份审；点"阅读全文"看完整材料，点"逐项审核"进对应条目区。可用 Ctrl+F 搜匿名编号。
4. 逐项判定：填 `H` 判定、`I` 原文证据、`J` 逐项理由、`N` 评阅人ID、`O` 评阅日期。
5. 数值登记 / 主张登记：列出**全部**科学数值与**全部**科学事实主张，不只列错的。确无则选"无科学数值/无科学主张"并留空登记行（空白 ≠ 零项）。
6. 回填 `审核总表` 的 G–O 列（含 M 评阅人ID、N 评阅日期、O 盲性申报）。
7. 两位评审**各自**回传一份 xlsx 原件。主持人保留原件，不做编辑。
8. 主持人做完整性校验（状态列、引用逐字性、枚举完整性），再做双评比对生成分歧清单。
9. 分歧清单逐条进 `02_仲裁记录`，由第三位同等背景者仲裁；仲裁后回填各表 `P/Q`（或 `U/V`）列。
10. 主持人按 §8 计算一致性指标并出报告。

## 7. 冻结量表要点（完整版见 docx 第 3 章 / xlsx `00_使用说明与冻结量表`）

**必答要点**：关键科学点命中 → `fact` 2=全部命中且无冲突 / 1=部分命中、不致结论反转 / 0=缺失或错误或命中禁答。
**限定语**：8 类（catalog_and_column、single_or_coadded、error_or_uncertainty、system_and_zeropoint、missing_or_sentinel、quality_flag、subset_scope、identity_source），2=全体现 / 1=缺1条 / 0=缺≥2条。
**数值来源**：traceable（等于 fixture/回包某列值，或明确引用文献并注明 verified/unverified）/ derivable（由可追溯值算出且写明方法与所缺改正）/ unsourced（其余全部）/ fatal（无来源且直接决定科学结论：周期、振幅、分类概率、零点、精度承诺、凭空红化）。
**边界规则**：数据不足时，正确回答是"该量在本表不存在/需另查 X"，而不是给一个看起来合理的数。
**红线 6 类**：`fatal_number`、`static_as_lc_conclusion`、`sentinel_calculation`、`identity_misattribution`、`absence_as_nonexistence`、`unmarked_as_constant`。**引用或否定错误前提不触发。**

> **口径提示**：量表 metrics 段写"SLR 分母 A+B+G = 16 题"，而离线主测实际分母为 14 题（16 题中 A04、G04 为在线辅测题，不并入离线主测）。逐项判定表已按实际口径列条目，评阅人**无须**自行判断分母。

## 8. 回收后的一致性统计口径

| 字段类型 | 统计量 | 阈值 |
|---|---|---|
| 逐项通过/未通过 | Cohen's kappa、raw agreement p0、Gwet's AC1 | 可接受 0.6 / 良好 0.8 |
| 有序字段 | quadratic weighted kappa、Krippendorff's alpha (ordinal) | 暂定 0.667 |
| 计数字段 | Krippendorff's alpha (interval)、ICC(2,1) | 暂定 0.667 |
| 可用性 | ICC(2,1)、Spearman rho、mean absolute difference | ICC 0.75 |

**报告必须包含**：κ / p0 / AC1 / α / ICC 全量；逐轴分层 κ；分歧项清单（题号 + 分歧类型 + 仲裁结果）；仲裁项占比。

> 高通过率下 κ 会被边际分布压低（κ 悖论），故须**并列报 AC1**，以区分"量表有歧义"与"题太简单"。

**效力提示**（来自冻结量表）：36 题配对设计下，真实差异 0.90 vs 0.70 时 McNemar 效力约 0.6–0.7，存在漏检风险；补救为每题 3 次重复取中位数，若要效力 ≥0.80 需扩至约 60–70 题。**报告中阴性结果必须讨论样本量是否不足。**

7. **不得把"已填写待核验"当作"科学合格"**。
